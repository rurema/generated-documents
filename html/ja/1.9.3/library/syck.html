    要約

    yaml のバックエンドライブラリです。YAML バージョン 1.0 を扱う事ができます。

    このライブラリは obsolete です。2.0.0 で削除されました。psych を使用してください。

    Syck

    yaml のバックエンドのためのモジュールです。

    サブライブラリ

    syck/basenode

    YAML のノードを検索するためのサブライブラリです。

    syck/constants

    YAML 関連の定数のためのサブライブラリです。

    syck/error

    YAML 関連のエラーを扱うためのサブライブラリです。

    syck/rubytypes

    Ruby の組み込みクラスのいくつかを YAML に変換するためのサブライブラリです。

    syck/stream

    複数の YAML ドキュメントを一度に扱うためのサブライブラリです。

    syck/stringio

    stringio ライブラリが使用できない環境を補助するためのサブライブラリです。

    syck/tag

    タグ URI とクラスを関連付けるためのサブライブラリです。

    syck/yamlnode

    YAML のノードを表現するためのサブライブラリです。

    syck/ypath

    YAML ドキュメントから特定のデータを検索する機能を提供するサブライブラリです。
