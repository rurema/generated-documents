    instance method Thread#alive?

    alive? -> bool[permalink][rdoc][edit]

    スレッドが「生きている」時、true を返します。

    例 
    thr = Thread.new { }
p thr.join              # => #<Thread:0x401b3fb0 dead>
p Thread.current.alive? # => true
p thr.alive?            # => false

    Thread#status が真を返すなら、このメソッドも真です。

    [SEE_ALSO] Thread#status, Thread#stop?
