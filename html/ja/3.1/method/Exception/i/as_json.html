    instance method Exception#as_json

    as_json(*args) -> HashRuby 3.0 から Ruby 4.1 で削除[permalink][rdoc][edit] [added by json/add/exception]

    self を JSON 形式の文字列に変換する際に使う、中間表現となるハッシュに変換して返します。 Exception#to_json が内部で使用しています。

    ハッシュには、JSON.create_id をキーとしてクラス名が、'm' にメッセージが、 'b' にバックトレースが入ります。

    [PARAM] args:
    無視されます。
    例 
    require 'json/add/exception'

hash = Exception.new('Foo').as_json
p hash['json_class'] # => "Exception"
p hash['m']           # => "Foo"
p hash['b']           # => nil
