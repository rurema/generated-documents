    singleton method YAML.dump

    dump(obj, io = nil) -> String | IO[permalink][rdoc]

    与えられた obj を YAML フォーマットに変換し、io に書き込みます。io を返します。io が与えられていない場合は、YAML フォーマットの文字列を返します。

    [PARAM] obj:
    YAMLフォーマットに変換されるオブジェクト
    [PARAM] io:
    出力先のIOオブジェクト 
    YAML.dump( ['badger', 'elephant', 'tiger'],
           File.open('sample.yml', 'w')    )
    フィードバックを送る
