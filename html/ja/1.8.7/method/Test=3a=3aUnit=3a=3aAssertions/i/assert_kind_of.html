    instance method Test::Unit::Assertions#assert_kind_of

    assert_kind_of(klass, object, message = "") -> ()[permalink][rdoc]

    object.kind_of?(klass) が真ならパスします。

    正確には、object が klass かそのサブクラスのインスタンスであるならパスします。また、klass がモジュールである場合は、object が klass をインクルードしたクラスかそのサブクラスのインスタンスであるならパスします。

    Test::Unit::Assertions#assert_instance_of との違いに注意して下さい。

    [PARAM] klass:
    期待するクラスかモジュールを与えます。
    [PARAM] object:
    検証するオブジェクトを指定します。
    [PARAM] message:
    assert が失敗した時に表示するメッセージを文字列で指定します。指定しなかった場合は表示しません。
    [EXCEPTION] Test::Unit::AssertionFailedError:
    assert が失敗した時に発生します。
