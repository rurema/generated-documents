    instance method ObjectSpace::WeakMap#length

    size -> IntegerRuby 2.1.0 から[permalink][rdoc][edit]
    length -> Integer

    保持しているエントリの数を返します。GC によって回収されたエントリは数えません。

    例 
    weak_map = ObjectSpace::WeakMap.new
key = "text"
weak_map[key] = "test"

p weak_map.size   # => 1
p weak_map.length # => 1
