    instance method Net::HTTP#max_retries=

    max_retries=(times)Ruby 3.0 から[permalink][rdoc][edit]

    冪等なリクエストが Net::ReadTimeout、IOError、EOFError、 Errno::ECONNRESET、Errno::ECONNABORTED、Errno::EPIPE、 OpenSSL::SSL::SSLError、Timeout::Error のいずれかで失敗した場合に再試行する最大回数を設定します。

    デフォルトは 1 です。

    [PARAM] times:
    再試行する最大回数を 0 以上の整数で指定します。負の値を指定した場合は ArgumentError が発生します。
    例 
    http = Net::HTTP.new(hostname)
http.max_retries = 2   # => 2
http.max_retries       # => 2
