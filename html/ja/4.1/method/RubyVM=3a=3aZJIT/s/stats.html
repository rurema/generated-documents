    singleton method RubyVM::ZJIT.stats

    stats(target_key = nil) -> Hash | object | nilRuby 4.0 から[permalink][rdoc][edit]

    ZJIT の統計情報を返します。

    --zjit-stats で統計収集を有効にしている場合、統計情報のカウンタ名をキーとするハッシュを返します。 target_key を指定した場合は、そのキーに対応する値だけを返します(該当するキーが無ければ nil)。統計収集が有効でない場合は nil を返します。

    [PARAM] target_key:
    取得したい統計情報のキーをシンボルで指定します。 
    # ruby --zjit-stats で実行した場合
RubyVM::ZJIT.stats.keys.first(3)  # => [:compiled_iseq_count, :failed_iseq_count, :compile_time_ns]
RubyVM::ZJIT.stats(:compiled_iseq_count) # => 12

    統計情報のキーの構成は処理系のバージョンによって変わります。

    [SEE_ALSO] RubyVM::ZJIT.stats_string, RubyVM::ZJIT.reset_stats!
