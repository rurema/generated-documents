    module function Math?.log10

    log10(x) -> Float[permalink][rdoc][edit]
    (double x) → Float

    x の常用対数（common logarithm）を返します。

    [PARAM] x:
    正の実数
    [EXCEPTION] TypeError:
    x に数値以外を指定した場合に発生します。
    [EXCEPTION] Math::DomainError:
    x に範囲外の実数を指定した場合に発生します。
    [EXCEPTION] RangeError:
    x に実数以外の数値を指定した場合に発生します。
    例 
    p Math.log10(1)     # => 0.0
p Math.log10(10)    # => 1.0
p Math.log10(10**100) # => 100.0
