    instance method IPAddr#to_hex

    to_hex -> StringRuby 4.1 から[permalink][rdoc][edit]

    IP アドレスの値を 16 進数表記の文字列で返します。

    IPv4 アドレスは 8 桁、IPv6 アドレスは 32 桁になるように、上位桁を 0 で埋めます。英字は小文字です。プリフィックス長(サブネットマスク)は結果に含まれません。プリフィックス長を指定して生成した場合は、マスクされた後のアドレスの値が対象になります。

    例 
    require 'ipaddr'
p IPAddr.new("192.168.1.1").to_hex   # => "c0a80101"
p IPAddr.new("0.0.0.1").to_hex       # => "00000001"
p IPAddr.new("3ffe:505:2::1").to_hex # => "3ffe0505000200000000000000000001"
p IPAddr.new("::1").to_hex           # => "00000000000000000000000000000001"
