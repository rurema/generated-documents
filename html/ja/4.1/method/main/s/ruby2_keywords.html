    singleton method main.ruby2_keywords

    ruby2_keywords(method_name, ...) -> nilRuby 2.7.0 から[permalink][rdoc][edit]

    トップレベルで定義したメソッドに、可変長引数(*args)で受けたキーワード引数を別のメソッド呼び出しへそのまま渡すためのフラグを設定します。

    Ruby 2.7 より前との後方互換性のために用意されているメソッドです。詳細は Module#ruby2_keywords を参照してください。

    [PARAM] method_name:
    メソッド名を String か Symbol で指定します。複数指定できます。
    例 
    def target(a, k: 0)
  [a, k]
end

def pass(*args)
  target(*args)
end
ruby2_keywords :pass

p pass(1, k: 2) # => [1, 2]

    [SEE_ALSO] Module#ruby2_keywords, Proc#ruby2_keywords, Hash.ruby2_keywords_hash
