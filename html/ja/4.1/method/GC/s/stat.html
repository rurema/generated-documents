    singleton method GC.stat

    stat(result_hash = {}, scope: :ractor) -> {Symbol => Integer}Ruby 1.9.3 から[permalink][rdoc][edit]
    stat(key, scope: :ractor) -> Numeric
    (?Hash[Symbol, untyped]? hash) → Hash[Symbol, untyped]
    (Symbol key) → Integer

    GC 内部の統計情報を Hash で返します。

    [PARAM] result_hash:
    戻り値のためのハッシュを指定します。省略した場合は新しくハッシュを作成します。result_hash の内容は上書きされます。
    [PARAM] key:
    得られる統計情報から特定の情報を取得したい場合にキーを Symbol で指定します。
    [PARAM] scope:
    統計情報の対象範囲を Symbol で指定します。:ractor(デフォルト)は現在の Ractor の値を返します。:local は :ractor の別名です。:global は、終了した Ractor の分も含む全 Ractor の累積の GC 回数と mark / sweep の CPU 時間を、stop-the-world の snapshot を取らずに返します。
    [EXCEPTION] ArgumentError:
    scope に未知の値を指定した場合に発生します。

    Ruby 4.1 から、キー :global_gc_count が加わりました。グローバル GC(全 Ractor を対象とする stop-the-world の GC)のうち、その Ractor が開始したものの回数です。各グローバル GC は、それを開始した 1 つの Ractor にだけ数えられるので、全 Ractor の :global_gc_count を足すとプロセス全体の回数になります。scope: :global では、終了した Ractor の分も含めたその合計を返します。グローバル GC は :major_gc_count には数えず、どちらのスコープでも :count は :minor_gc_count、:major_gc_count、:global_gc_count の合計になります。

    scope: :global のときに返るキーは :count、:time、:marking_time、:sweeping_time、:minor_gc_count、:major_gc_count、:global_gc_count の 7 つだけです。 scope を指定しない場合は、従来どおり現在の Ractor の値を返します。GC.count と GC.total_time も同様です。

    例 
    r = Ractor.new { GC.start; GC.stat(:count) }
p r.value                         # => 1
p GC.stat(:count)                 # => 0 (main Ractor の値)
p GC.stat(:count, scope: :global) # => 2
p GC.stat(:global_gc_count, scope: :global) # => 1
    [RETURN]
    GC 内部の統計情報をHash で返します。引数 key を指定した場合は数値を返します。
