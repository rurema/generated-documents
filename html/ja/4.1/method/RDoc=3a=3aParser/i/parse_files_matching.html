    instance method RDoc::Parser#parse_files_matching

    parse_files_matching(regexp) -> ()Ruby 1.9.3 から[permalink][rdoc][edit]

    regexp で指定した正規表現にマッチするファイルを解析できるパーサとして、自身を登録します。

    [PARAM] regexp:
    正規表現を指定します。

    新しいパーサを作成する時に使用します。

    例 
    class RDoc::Parser::Xyz < RDoc::Parser
  parse_files_matching /\.xyz$/
  # ...
end
    フィードバックを送る / このマニュアルを編集する
