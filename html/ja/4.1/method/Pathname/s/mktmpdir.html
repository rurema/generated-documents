    singleton method Pathname.mktmpdir

    mktmpdir -> PathnameRuby 3.4 から[permalink][rdoc][edit]
    mktmpdir {|dir| ... } -> object

    一時ディレクトリを作成し、そのパスを Pathname オブジェクトでラップして返します。

    ブロックを指定した場合は、ブロックの終了時にディレクトリを削除します。ブロックの評価値を返します。

    例 
    require 'pathname'

Pathname.mktmpdir {|dir|
  p dir.class   # => Pathname
  # 出力例: 動作環境により出力は異なります。
  p dir         # => #<Pathname:/tmp/d20260909-5-7sp1c2>
}
