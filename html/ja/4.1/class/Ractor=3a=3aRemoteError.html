    要約

    他の Ractor で発生した例外を、その結果を待っている Ractor に伝えるために発生します。

    もとの例外は Exception#cause で取得できます。 

    r = Ractor.new { raise "boom" }
begin
  r.value
rescue Ractor::RemoteError => e
  p e.message       # => "thrown by remote Ractor."
  p e.cause.message # => "boom"
end
