    module REXML::Validation::Validator

    [edit]
    クラス・モジュールの継承リスト:
    1. REXML::Validation::Validator

    要約

    バリデータに共通の機能を提供するモジュールです。

    REXML::Validation::RelaxNG がこのモジュールを include しています。

    目次

    インスタンスメソッド
    • dump
    • reset
    • validate
    定数
    • NILEVENT

    インスタンスメソッド

    dump -> nil[permalink][rdoc][edit]

    スキーマから作られた内部の状態を標準出力に出力します。

    デバッグ用のメソッドです。

    reset -> self[permalink][rdoc][edit]

    検証の状態を最初に戻します。

    同じバリデータで別の文書を検証するときは、検証を始める前にこのメソッドを呼んでください。

    validate(event) -> ()[permalink][rdoc][edit]

    パーサのイベント event が、スキーマから見て次に来てよいものであるかを検証します。

    通常は REXML::Validation::RelaxNG#receive を通じて呼ばれます。

    [PARAM] event:
    パーサのイベント
    [EXCEPTION] REXML::Validation::ValidationException:
    文書がスキーマに合わないときに発生します

    定数

    NILEVENT -> Array[permalink][rdoc][edit]

    内部用なのでユーザは使わないでください。
