    要約

    不正な CSV をパースしようとしたときに発生する例外です。

    入力に不正なバイト列が含まれていた場合は、サブクラスの CSV::InvalidEncodingError が発生します。

    特異メソッド

    new(message, line_number) -> CSV::MalformedCSVErrorRuby 2.6.0 から[permalink][rdoc][edit]

    例外オブジェクトを生成して返します。

    例外のメッセージは message の後ろに " in line #{line_number}." を付けたものになります。line_number は CSV::MalformedCSVError#line_number の戻り値になります。

    [PARAM] message:
    エラーメッセージを表す文字列を指定します。
    [PARAM] line_number:
    例外が発生した行の行番号を指定します。
    例 
    require "csv"

e = CSV::MalformedCSVError.new("Illegal quoting", 3)
p e.message     # => "Illegal quoting in line 3."
p e.line_number # => 3

    インスタンスメソッド

    line_number -> IntegerRuby 2.6.0 から[permalink][rdoc][edit]
    lineno -> Integer

    例外が発生した行の行番号を返します。

    例 
    require "csv"

begin
  CSV.parse("a,b\n\"c,d\n")
rescue CSV::MalformedCSVError => e
  p e.line_number # => 2
  p e.lineno      # => 2
  p e.message     # => "Unclosed quoted field in line 2."
end
