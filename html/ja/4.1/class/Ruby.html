    module Ruby

    [edit]
    クラス・モジュールの継承リスト:
    1. Ruby

    要約

    Ruby の実装間で可搬な情報を集めたモジュールです。 Ruby 4.0 で導入されました。

    このモジュールで定義されている定数は、トップレベルで RUBY_ を接頭辞に付けた定数（RUBY_VERSION など）と同じ値で参照できます。たとえば Ruby::VERSION と Object::RUBY_VERSION は同じ文字列を返します。

    また、このモジュールの下には、クラスやモジュールをプロセス内で隔離する実験的機能のためのクラス Ruby::Box も定義されています。

    COPYRIGHT -> StringRuby 4.0 から[permalink][rdoc][edit]

    Ruby のコピーライトを表す文字列。

    トップレベル定数 Object::RUBY_COPYRIGHT と同じ値です。

    DESCRIPTION -> StringRuby 4.0 から[permalink][rdoc][edit]

    Ruby の詳細を表す文字列。

    ruby -v で表示される内容が格納されています。トップレベル定数 Object::RUBY_DESCRIPTION と同じ値です。

    ENGINE -> StringRuby 4.0 から[permalink][rdoc][edit]

    Ruby 処理系実装の種類を表す文字列。

    トップレベル定数 Object::RUBY_ENGINE と同じ値です。

    ENGINE_VERSION -> StringRuby 4.0 から[permalink][rdoc][edit]

    Ruby 処理系実装のバージョンを表す文字列。

    トップレベル定数 Object::RUBY_ENGINE_VERSION と同じ値です。

    PATCHLEVEL -> 0Ruby 4.0 から[permalink][rdoc][edit]

    Ruby のパッチレベルを表す Integer オブジェクトです。

    Ruby 4.0 以降はパッチレベルの増分をやめたため、リリース版では常に 0 になります（master などの開発版では -1 になります）。トップレベル定数 Object::RUBY_PATCHLEVEL と同じ値です。

    PLATFORM -> StringRuby 4.0 から[permalink][rdoc][edit]

    プラットフォームを表す文字列。

    トップレベル定数 Object::RUBY_PLATFORM と同じ値です。

    RELEASE_DATE -> StringRuby 4.0 から[permalink][rdoc][edit]

    Ruby のリリース日を表す文字列。

    トップレベル定数 Object::RUBY_RELEASE_DATE と同じ値です。

    REVISION -> StringRuby 4.0 から[permalink][rdoc][edit]

    Ruby の GIT コミットハッシュを表す String オブジェクトです。

    トップレベル定数 Object::RUBY_REVISION と同じ値です。

    VERSION -> StringRuby 4.0 から[permalink][rdoc][edit]

    Ruby のバージョンを表す文字列。

    Ruby のバージョンは、major.minor.teeny という形式です。トップレベル定数 Object::RUBY_VERSION と同じ値です。
