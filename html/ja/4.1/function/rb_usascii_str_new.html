    function rb_usascii_str_new

    [edit]
    VALUE rb_usascii_str_new(const char *ptr, rb_len_t len)

    US-ASCII の新しい String を作成します。 rb_str_new と同じですが、エンコーディングが US-ASCII になります。 rb_external_str_new とは異なり、内容の変換はしません。

    [PARAM] ptr:
    文字列の内容を持つ、len バイト以上のメモリ領域です。
    [PARAM] len:
    ptr の長さです。終端の NUL 文字を含まないバイト数で指定します。
    [RETURN]
    ptr の内容をそのままコピーした、長さ len バイトで US-ASCII の新しい String です。
    [EXCEPTION] NoMemoryError:
    len+1 バイトの確保に失敗したとき。
    [EXCEPTION] ArgumentError:
    len が負のとき。
