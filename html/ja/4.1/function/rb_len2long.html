    function rb_len2long

    [edit]
    long rb_len2long(rb_len_t n)

    rb_len_t の値 n を long に変換します。 long に収まらないときは rb_out_of_long によって RangeError が発生します。 rb_len_t が long の環境では常に成功します。 64 ビットの mswin で、長さを long で保持している拡張ライブラリが使います。 [feature#22400]
