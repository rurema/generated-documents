    macro RB_NOGVL_PENDING_INTR_FAIL

    [edit]
    int RB_NOGVL_PENDING_INTR_FAIL

    rb_nogvl の flags に指定するフラグです。現在のスレッドに保留中の割り込みがあるとき、Thread.handle_interrupt でマスクされた割り込みも含めて、ブロッキング領域に入らず、func も呼ばずに 0 を返します。 errno は RB_NOGVL_INTR_FAIL による既存のスキップ時と同じく、func が呼ばれていないため 0 です。
