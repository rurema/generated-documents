    function rb_str_vcatf

    [edit]
    VALUE rb_str_vcatf(VALUE dst, const char *fmt, va_list ap)

    rb_str_catf と同じですが、値を va_list で渡します。 rb_vsprintf の結果を、新しい文字列を作る代わりに、指定した文字列の末尾に追加します。 rb_str_append(dst, rb_vsprintf(fmt, ap)) と同じ結果になります。

    [PARAM] dst:
    追加先の String です。
    [PARAM] fmt:
    printf のような書式文字列です。
    [PARAM] ap:
    書式に埋め込む値です。
    [RETURN]
    引数の dst です。
    [EXCEPTION] TypeError:
    dst が String でないとき。
