    C API 関数一覧

    Ruby の C API(C 言語 API)の関数の一覧です。Ruby 本体や拡張ライブラリの開発に使うもので、Ruby プログラムから直接呼び出す関数ではありません。

    ALLOC

    type 型のメモリを割り当てる。

    ALLOC_N

    type 型のメモリを n 個割り当てる。

    ALLOCA_N

    type 型のメモリを n 個スタックフレームに割り当てる。このメモリは関数が終わると自動的に解放される。

    BUILTIN_TYPE

    obj の構造体型 ID を返します。 SPECIAL_CONST_P(obj) が真のオブジェクトに対して使うと落ちます。

    Check_Type

    val の構造体型フラグが typeflag でなければ例外 TypeError を発生します。val は即値の VALUE であっても構いません。

    CHR2FIX

    char 型の整数 x を Ruby の Fixnum に変換します。

    CLASS_OF

    obj のクラスを返します。この場合の「クラス」とは C レベルのクラス、つまり RBasic 構造体の klass メンバの値です。また、構造体を持たない Fixnum などに対しても正常に働きます。

    CLONESETUP

    OBJSETUP() の変種。 clone を、obj から clone で作ったオブジェクトとして初期化します。

    DATA_PTR

    実際は struct RData* 型である dta から、それがラップしているポインタを取り出します。

    DUPSETUP

    OBJSETUP() の変種。 dup を、obj から dup で作ったオブジェクトとして初期化します。

    FIX2INT

    Fixnum を int に変換します。返り値が int の範囲から外れる場合は RangeError が発生します。

    FIX2LONG

    Fixnum を long に変換します。 Fixnum は常に long に収まります。

    FIX2UINT

    Fixnum を unsigned int に変換します。返り値が unsigned int の範囲から外れる場合は RangeError が発生します。

    FIX2ULONG

    Fixnum を unsigned long に変換します。範囲のチェックは行われません。負の Fixnum を渡した場合は例外にはならず、 2 の補数表現をそのまま unsigned long として解釈した大きな値を返します。

    FIXABLE

    f が Fixnum の範囲に収まっているなら真。

    FIXNUM_MAX

    Fixnum にできる整数の上限値。

    FIXNUM_MIN

    Fixnum にできる整数の下限値。

    FIXNUM_P

    obj が Fixnum のインスタンスのとき真。

    FL_ABLE

    x が即値の VALUE でなければ真。

    FL_REVERSE

    x のフラグ f を反転する。

    FL_SET

    x に対してフラグ f をセットする。

    FL_TEST

    x のフラグ f が立っていたら真。

    FL_UNSET

    x のフラグ f をクリアする。

    HAVE_RB_LEN_T

    rb_len_t と rb_ulen_t、および LEN2NUM や NUM2LEN、PRIdLEN などのマクロが使えることを示すマクロです。値は 1 です。古い版もサポートする拡張ライブラリは、これが未定義のときに typedef long rb_len_t; やマクロを自前で定義して代用できます。

    ID2SYM

    id を Symbol に変換します。

    IMMEDIATE_P

    obj が即値でかつ真な値であるとき真。すなわち現在の実装では obj が Symbol か Fixnum のインスタンスであるか、 Qtrue のとき真。

    INT2FIX

    Fixnum におさまることが自明な整数を Fixnum に変換します。なお、Fixnum の幅は long の幅 - 1 です。

    INT2NUM

    任意の整数を Integer に変換します。 INT2FIX と異なり、Fixnum におさまらない整数も扱えます。

    ISALNUM
    ISALPHA
    ISASCII
    ISDIGIT

    cが'0'から'9'のとき真。それ以外は偽。

    ISLOWER
    ISPRINT
    ISSPACE
    ISUPPER
    ISXDIGIT

    cが’0’から’9’、’a’から’f’、’A’から’F’のとき真。それ以外は偽。

    LEN2NUM

    rb_len_t の値 n を Fixnum か Bignum に変換します。 rb_len_t が long の環境では LONG2NUM、64 ビットの mswin では LL2NUM と同じです。

    LL2NUM 例 
    long long n = 42;
VALUE num = LL2NUM(n); // (long longの整数42をRubyのオブジェクトに変換)
    LONG2FIX

    INT2FIX と同じです。

    LONG2NUM
    MEMCMP

    type 型のメモリ領域 p1 と p2 の先頭 n 個を比較する。 p1 が p2 の最初の n 個より小さい、等しい、大きいとき、それぞれ正、0、負の値を返す。

    MEMCPY

    type 型のメモリ領域 p2 のうち先頭の n 個を p1 にコピーする。

    MEMMOVE

    type 型のメモリ領域 p2 のうち先頭の n 個を p1 に移動する。

    MEMZERO

    type 型のメモリ領域 p をゼロクリアする。 n は要素数。

    NEGFIXABLE

    f が Fixnum の下限値以上ならば真。

    NIL_P

    obj が Qnil のとき真。

    NUM2CHR
    NUM2DBL
    NUM2INT

    x を int 型の整数に変換します。

    NUM2LEN

    x を rb_len_t に変換します。 rb_len_t が long の環境では NUM2LONG、64 ビットの mswin では NUM2LL と同じです。 rb_len_t の範囲に収まらないときは RangeError が発生します。

    NUM2LL

    Numeric のオブジェクト x を、C の long long に変換します。逆の変換には LL2NUM を使います。

    NUM2LONG

    x を long 型の整数に変換します。

    NUM2OFFT

    Numeric のオブジェクト x を、C の off_t に変換します。 off_t の大きさに応じて、long long、long、int への変換のどれかと同じになります。

    NUM2SHORT

    x を short 型の整数に変換します。

    NUM2SIZET

    Integer のオブジェクト x を、C の size_t に変換します。

    NUM2SSIZET

    Integer のオブジェクト x を、C の ssize_t に変換します。

    NUM2UINT

    x を unsigned int 型の整数に変換します。

    NUM2ULL

    Numeric のオブジェクト x を、C の unsigned long long に変換します。

    NUM2ULONG

    x を unsigned long 型の整数に変換します。

    NUM2USHORT

    x を unsigned short 型の整数に変換します。

    OBJ_FREEZE
    OBJ_FROZEN
    OBJSETUP

    obj をクラス klass とフラグ typeflag で初期化する。

    POSFIXABLE

    f が Fixnum の上限値以下ならば真。

    PRIdLEN

    rb_len_t の値を printf 系の関数で出力するための書式指定子です。 PRIdLEN、PRIiLEN、PRIoLEN、PRIuLEN、PRIxLEN、PRIXLEN があり、それぞれ d、i、o、u、x、X 変換に対応します。 "%" PRIdLEN のように書式文字列に連結して使います。 rb_len_t の幅に合わせて、long の環境では "l"、64 ビットの mswin では 64 ビット整数用の接頭辞が付きます。

    RARRAY

    obj を struct RArray* にキャストする。本当は obj が struct RArray* でないとしてもキャストしてしまう。

    rb_add_event_hook

    インタプリタのイベントに対するフック関数を登録します。 events に指定したイベントが起きると func が呼ばれます。

    rb_alias

    クラス klass に定義されたメソッド name の本体を実体とする新しいメソッド def を定義します。

    rb_alias_variable
    rb_any_to_s

    Object#to_s の実体です。

    rb_apply

    オブジェクト recv のメソッド mid を引数 args とともに呼び出します。

    rb_Array

    obj が Array でない場合は to_a を使って Array に変換します。

    rb_ary_aref

    argc が 1 のときは ary[*argv]、 2 のときは ary[argv[0], argv[1]] を返します。

    rb_ary_cat

    配列 ary の末尾に、train が指す len 個のオブジェクトを破壊的に追加します。

    rb_ary_clear

    ary.clear

    rb_ary_concat

    ary.concat x

    rb_ary_delete

    ary.delete

    rb_ary_entry

    ary のインデックス offset の要素を返します。

    rb_ary_includes

    ary.include? item

    rb_ary_new

    空の Ruby の配列を作成し返します。

    rb_ary_new2

    長さ len 分だけメモリを確保した、長さゼロの Ruby の配列を作成し返します。

    rb_ary_new3

    長さ n で要素に i0 i1 i2 …を格納した Ruby の配列を作成し返します。

    rb_ary_new4

    rb_ary_new_from_values の古い名前です。新しく書くコードでは rb_ary_new_from_values を使ってください。

    rb_ary_new_capa

    要素を持たない配列を作成します。内部のバッファは capa 個の要素分を確保します。配列が最終的にある大きさまで育つと分かっているときは、サイズ変更を繰り返すよりも効率的です。

    rb_ary_new_from_args

    可変長引数で渡されたオブジェクトから、要素数 n の配列を作成します。

    rb_ary_new_from_values

    C の配列で渡されたオブジェクトから、要素数 n の配列を作成します。 rb_ary_new_from_args とは、オブジェクトの渡し方だけが異なります。

    rb_ary_pop

    配列 ary の末尾の要素をとりのぞき返します。空配列のときは Qnil を返します。

    rb_ary_push

    配列 ary の末尾に item を追加します。

    rb_ary_shift

    配列 ary の先頭の要素を取り除き返します。空配列のときは Qnil を返します。

    rb_ary_sort

    ary.sort

    rb_ary_store

    配列 ary のインデックス idx に val を格納します。idx が範囲を越えるときは Ruby レベルと同じく自動的にサイズが拡張されます。

    rb_ary_subseq

    配列 ary の一部を、新しい配列として取り出します。

    rb_ary_to_ary

    オブジェクトを強制的に配列にします。まず obj の to_ary メソッドを試し、結果があればそれを返します。そうでなければ、obj だけを要素とする長さ 1 の配列を作って返します。

    rb_ary_to_s

    ary.to_s

    rb_ary_unshift

    配列 ary の先頭に item を挿入します。

    rb_assoc_new

    [a,b] を返します。

    rb_attr
    rb_autoload_load
    rb_backref_get

    現在の SCOPE の $~ の値を返します。

    rb_backref_set

    現在の SCOPE の $~ に val を代入します。

    rb_backtrace
    rb_block_call

    obj のメソッド mid を、C の関数 proc をブロックとして渡して呼び出します。 rb_funcallv にブロックとして関数を渡せるようにしたものです。

    rb_block_call_kw

    rb_block_call と同じですが、argv の最後の要素をキーワード引数として扱うかどうかを kw_splat で指定します。

    rb_block_given_p

    メソッドがブロック付きで呼ばれていれば true を返します。

    rb_bug

    インタプリタをただちに異常終了させます。インタプリタ自身のバグが原因の状況で呼ばれることを想定した関数で、例外処理も ensure の実行もしません。可能であれば、内部状態やスタックトレース、レジスタの値をデバッグ用に表示します。

    rb_call_super

    Rubyレベルでの super です。現在評価中のメソッドのスーパークラスのメソッドを呼び出します。

    rb_catch

    catch と同等の動作を実行します。

    rb_check_arity

    引数の個数 argc が min 以上 max 以下の範囲にあることを検査します。 max に UNLIMITED_ARGUMENTS を指定すると、上限は検査しません。範囲外のときは ArgumentError が発生します。 rb_scan_args が使えるときは、そちらのほうが強力で分かりやすいので、そちらを使ってください。

    rb_check_convert_type

    val.method を実行してクラス tname のインスタンスを返します。 val がメソッド method を持たなければ nil を返します。

    rb_class2name

    klass の名前を返します。返り値の内容を変更したり free してはいけません。

    rb_class_instance_methods

    Module#instance_methods の実体。モジュール mod に定義されている public メソッド名のリストを文字列の配列で返します。

    rb_class_new

    super をスーパークラスとして新しいクラスオブジェクトを生成し、返します。

    rb_class_new_instance

    Class#new の実体です。

    rb_class_path

    klass の名前を返します。klassが無名クラス、無名モジュールの場合 #<Class 0xXXXX>, #<Module 0xXXXX> の形式で返します。

    rb_class_private_instance_methods

    Module#private_instance_methods の実体。モジュール mod に定義されている private メソッド名のリストを文字列の配列で返します。

    rb_class_protected_instance_methods

    Module#protected_instance_methods の実体。モジュール mod に定義されている protected メソッド名のリストを文字列の配列で返します。

    rb_class_real

    特異クラスや化身クラス (T_ICLASS) を飛ばして cl のスーパークラスを辿り、Ruby レベルに露出してもよいクラスを返します。

    rb_class_superclass
    rb_const_defined

    klass とそのスーパークラスに定数 id が定義されていれば真。

    rb_const_defined_at

    klass 自体に定数 id が定義されていれば真。

    rb_const_get

    定数 klass::name の値を取得します。

    rb_const_get_at

    クラス klass で定義された定数 name の値を取得します (祖先や外のクラスは調べない)。

    rb_const_list
    rb_const_set

    定数 klass::name の値を val として定義します。

    rb_convert_type

    オブジェクト val をクラス type のインスタンスに変換します。変換には、val.method の戻り値が使われます。

    rb_copy_generic_ivar
    rb_cstr_to_dbl
    rb_cv_get

    klass のクラス変数 name の値を取得します。

    rb_cv_set

    klass のクラス変数 name に val を代入します。変数がまだ定義されていない場合は NameError を発生します。

    rb_cvar_defined
    rb_cvar_get

    klass のクラス変数 name の値を取得します。

    rb_cvar_set

    klass のクラス変数 name に val を代入します。変数がまだ定義されていない場合は NameError を発生します。

    rb_define_alias

    クラス klass のインスタンスメソッド old の別名 new を定義します。

    rb_define_attr

    クラス klass にメソッド name と name= を定義します。 read が真のときは name を定義し、 write が真のときは name= を定義します。

    rb_define_class

    クラス super の下位クラス name を作成し返します。

    rb_define_class_id

    クラス名 id でクラス super を継承したクラスを新しく作成する。クラス→クラス名 (定数名) の関連付けはなされるが、定数→クラスの関連付けはなされない。

    rb_define_class_under

    super のサブクラスとして新しい Ruby クラスを、outer の定数として定義して返します。

    rb_define_class_variable

    クラス klass のクラス変数 name を初期値 val で定義します。既に同名の変数が定義されていたら警告します。

    rb_define_const

    クラス klass の定数 name を初期値 val で定義します。既に同名の定数が定義されていたら警告します。

    rb_define_global_const

    トップレベル (現在は Object) の定数 name を初期値 val で定義します。既に同名の定数が定義されていたら警告します。

    rb_define_global_function

    関数 name を定義します。 func と argc は rb_define_method と同じです。

    rb_define_hooked_variable
    rb_define_method

    クラスklassのインスタンスメソッドnameを定義します。

    rb_define_method_id

    klass に public メソッド name を定義します。その実体は関数 func です。また argc の意味は rb_define_method と同じです。

    rb_define_module

    モジュール name を作成し返します。

    rb_define_module_function

    モジュール module にモジュール関数 name を定義します。 func と argc は rb_define_method と同じです。

    rb_define_module_id

    名前が id である新しいモジュールを定義し、それを返します。モジュール→名前 (定数) のリンクは確立しますが名前→モジュールのリンクはまだ確立していません。

    rb_define_module_under

    モジュール outer::name を作成し返します。

    rb_define_private_method

    クラス klass にプライベートインスタンスメソッド name を定義します。その実体は関数 func であり、その関数がとる引数のタイプを argc で指定します。argc のフォーマットについては rb_define_method の項を参照してください。

    rb_define_protected_method

    クラス klass に protected インスタンスメソッド name を定義します。その実体は関数 func であり、その関数がとる引数のタイプを argc で指定します。argc のフォーマットについては rb_define_method の項を参照してください。

    rb_define_readonly_variable
    rb_define_singleton_method

    obj に特異メソッド name を定義します。メソッドの実体を func に関数ポインタで与え、その関数がとる引数のタイプを argc に渡します。argc のフォーマットについては rb_define_method の記述を参照してください。

    rb_define_variable
    rb_define_virtual_variable
    rb_enc_str_new

    エンコーディングを指定して、新しい String を作成します。 rb_str_new と同じですが、エンコーディング enc を持つ文字列になります。

    rb_enc_str_new_cstr

    エンコーディングを指定して、C の文字列から新しい String を作成します。 rb_enc_str_new と同じですが、ptr が C の文字列であると仮定して長さを求めます。 rb_str_new_cstr と同じですが、エンコーディング enc を持つ文字列になります。

    rb_enc_str_new_literal

    エンコーディングを指定して、C の文字列リテラルから新しい String を作成します。文字列リテラルの領域を、そのまま文字列の実体として使います。文字列リテラルしか渡せません。変数は渡せません。

    rb_ensure

    ensure の C 版です。まず body(data1) を実行し、その途中で例外や exit が起きたとしても ensure(data2) が確実に実行されます ( body() が正常終了しても実行されます)。

    rb_eql

    obj1.equal?(obj2) ならば Qtrue、そうでないならば Qfalse。

    rb_equal

    obj1 == obj2 ならば Qtrue、そうでないならば Qfalse。

    rb_eval_string

    str を Ruby プログラムとしてコンパイル・評価し、その値を返します。

    rb_eval_string_protect

    str を Ruby プログラムとしてコンパイル・評価し、その値を返します。

    rb_eval_string_wrap

    rb_eval_string_protect と同じですが、スクリプトの評価を無名のモジュールのもとで行います。

    rb_exc_fatal

    例外オブジェクト err を fatal として投げます。

    rb_exc_raise

    例外オブジェクト err を投げます。

    rb_exit

    ステータス status でインタプリタを終了させます。

    rb_extend_object
    rb_extract_keywords

    ハッシュを、シンボルをキーとする部分とそれ以外に分けます。シンボルをキーとする部分は新しいハッシュとして返します。残りは新しいハッシュとして orighash が指す先に格納します。元のハッシュは変更しません。

    rb_f_abort
    rb_f_exit
    rb_f_global_variables
    rb_f_require

    require の実体。 self == obj として fname を require します。

    rb_f_trace_var
    rb_f_untrace_var
    rb_fatal

    あらゆる例外処理をスキップして即座にインタプリタが終了します。 fmt とその後の引数は printf と同じ形式でエラーメッセージを表現します。

    rb_fd_clr

    ファイルディスクリプタ fd を、f から取り除きます。 FD_CLR(3) に相当します。

    rb_fd_init

    rb_fdset_t を初期化します。ほかの rb_fd_* を使う前に、必ず初期化してください。 fd_set のためのメモリを malloc(3) で確保することに相当します。初期化後の f はファイルディスクリプタを持ちません。

    rb_fd_isset

    ファイルディスクリプタ fd が f に含まれているかどうかを調べます。 FD_ISSET(3) に相当します。

    rb_fd_set

    ファイルディスクリプタ fd を、f に追加します。 FD_SET(3) に相当します。

    rb_fd_term

    rb_fdset_t を破棄し、使っていたメモリなどの資源を解放します。 fd_set のメモリを free(3) で解放することに相当します。再び使うには、rb_fd_init で初期化し直す必要があります。破棄後の f はファイルディスクリプタを持ちません。

    rb_fd_zero

    f からすべてのファイルディスクリプタを取り除きます。 FD_ZERO(3) に相当します。

    rb_fix_new
    rb_Float
    rb_float_new

    C の double の値 d を、Float のインスタンスに変換します。

    RB_FLOAT_TYPE_P

    obj が Float のインスタンスかどうかを調べます。

    rb_free_generic_ivar
    rb_funcall

    recv に対してメソッド name を呼びだし、メソッドの返り値を返します。プライベートメソッドも呼びだせます。

    rb_funcall2

    recv に対してメソッド name を呼びだし、メソッドの返り値を返します。プライベートメソッドも呼びだせます。

    rb_funcall3

    rb_len_t が取りうる最小値です。 long の環境では LONG_MIN、64 ビットの mswin では INT64_MIN です。

    rb_len_t

    String や Array、MatchData の長さや添字を表す符号付き整数型です。 long ですが、64 ビットの mswin (Visual C++ でビルドした 64 ビット Windows 版) では long が 32 ビットのままポインタが 64 ビットなので、int64_t として定義されます。 32 ビットの mswin と MinGW 版では long です。 RSTRING_LEN や rb_range_beg_len など、長さを受け渡す C API はこの型を使います。拡張ライブラリはこれらの長さを long ではなく rb_len_t で保持してください。 64 ビットの mswin では、長さを long で保持すると 2GiB で切り詰められ、rb_range_beg_len などの出力引数に long * を渡すとコンパイルエラーになります。 long が必要なときは rb_len2long で変換してください。また 64 ビットの mswin では ABI も変わるため、拡張ライブラリの再ビルドが必要です。古い版もサポートする拡張ライブラリは、HAVE_RB_LEN_T が未定義のときに typedef long rb_len_t; などで代用できます。 extconf.rb からは RbConfig::SIZEOF["rb_len_t"] で大きさを取得できます。なお 64 ビットの mswin でも Fixnum の範囲 (FIXNUM_MAX) は 31 ビットのままなので、LEN2NUM の結果は 2**30 以上で Bignum になります。 [feature#22400]

    rb_nogvl

    func を GVL を解放して呼び出します。 rb_thread_call_without_gvl と同じですが、動作を変える flags を追加で受け取ります。 func を呼ぶ前に保留中の割り込みを処理し、func から戻って GVL を再取得したあとで、その間に発生した割り込みを処理します。他のスレッドから Thread#kill などで割り込まれたときは ubf が呼ばれます。 func の中では、メソッド呼び出しや例外の発生など、ほとんどの Ruby の C API は使えません。

    RB_NOGVL_INTR_FAIL

    rb_nogvl の flags に指定するフラグです。 func から戻ったあとで割り込みを処理しなくなります。代わりに、ブロッキング領域に入る前に割り込みを検出したときは、func を呼ばずに戻ります。 func の副作用を考慮したうえで、あとから呼び出し側で割り込みを確認できます。

    RB_NOGVL_OFFLOAD_SAFE

    rb_nogvl の flags に指定するフラグです。 func をバックグラウンドのスレッドやワーカープールにオフロードしても安全であることを示します。つまり func を Fiber スケジューラの blocking_operation_wait フックで実行できます。 func がスレッドローカルストレージやスレッド固有のデータ操作 (たとえば Mutex の unlock) に依存するときは、別のスレッドでは動作が異なったり失敗したりするため、指定しないでください。

    RB_NOGVL_PENDING_INTR_FAIL

    rb_nogvl の flags に指定するフラグです。現在のスレッドに保留中の割り込みがあるとき、Thread.handle_interrupt でマスクされた割り込みも含めて、ブロッキング領域に入らず、func も呼ばずに 0 を返します。 errno は RB_NOGVL_INTR_FAIL による既存のスキップ時と同じく、func が呼ばれていないため 0 です。

    RB_NOGVL_UBF_ASYNC_SAFE

    rb_nogvl の flags に指定するフラグです。渡した ubf がシグナルハンドラから呼べる (async-signal-safe な) 関数であることを示します。 async-signal-safe でない ubf でも問題ないため、よく分からなければ指定しなくて構いません。

    RUBY_TYPED_EMBEDDABLE

    rb_data_type_t の flags に指定するフラグです。 Ruby 3.3 で追加され、4.1 で公開 API として文書化されました。 [feature#21853] Ruby は C の構造体を malloc で別に確保せず、オブジェクトのスロットに直接埋め込むことがあります。ポインタをたどる回数や malloc の負荷が減り、場合によってはメモリ使用量も減ります。ただし保証ではなく、構造体がスロットに収まらないときなどは埋め込まれません。

    ruby_xcalloc

    引数と返り値は calloc() と同じです。ただしメモリ割り当てに失敗したときは GC を行いそれでもだめなときは例外 NoMemoryError を発生します。つまりこの関数が返り値を返したときは常に割り当ては成功です。

    ruby_xfree

    以前 malloc/calloc/realloc して free していないポインタ x を開放します。ruby のシグナル機構とコンフリクトしません。

    ruby_xfree_sized

    ruby_xfree と同じですが、確保したときの大きさ size を受け取ります。 C23 の free_sized に倣った関数で、GC がメモリ使用量をより正確に追跡できます。 size は ptr を確保したときの大きさと正確に一致していなければならず、誤った大きさを渡すと未定義動作になり、クラッシュやメモリリークを起こすことがあります。 [feature#21861]

    ruby_xmalloc

    引数と返り値は malloc() と同じ。ただしメモリ割り当てに失敗したときは GC を行いそれでもだめなときは NoMemoryError を raise する。つまりこの関数が返り値を返したときは常に割り当ては成功している。

    ruby_xrealloc

    引数と返り値の意味は realloc() と同じ。ただしメモリ割り当てに失敗したときは GC を行いそれでもだめなときは NoMemoryError を raise する。つまりこの関数が返り値を返したときは常に割り当ては成功している。

    ruby_xrealloc2_sized

    ruby_xrealloc2 と同じですが、現在の要素数 oldelems を受け取ります。 oldelems は ptr を確保したときの要素数と正確に一致していなければならず、誤った大きさを渡すと未定義動作になります。 [feature#21861]

    ruby_xrealloc_sized

    ruby_xrealloc と同じですが、現在の大きさ oldsiz を受け取ります。 oldsiz は ptr を確保したときの大きさと正確に一致していなければならず、誤った大きさを渡すと未定義動作になります。 [feature#21861]
