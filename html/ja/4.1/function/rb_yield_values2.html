    function rb_yield_values2

    [edit]
    VALUE rb_yield_values2(int n, const VALUE *argv)

    n 個の引数をブロックに yield します。 rb_yield_values と同じですが、引数を C の配列 argv で渡します。

    [PARAM] n:
    ブロックに渡す引数の個数です。
    [PARAM] argv:
    ブロックに渡す引数の配列です。
    [RETURN]
    ブロックの評価結果です。
    [EXCEPTION] LocalJumpError:
    ブロックが渡されていないとき。
