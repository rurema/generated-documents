    function ruby_xfree_sized

    [edit]
    void ruby_xfree_sized(void *ptr, size_t size)

    ruby_xfree と同じですが、確保したときの大きさ size を受け取ります。 C23 の free_sized に倣った関数で、GC がメモリ使用量をより正確に追跡できます。 size は ptr を確保したときの大きさと正確に一致していなければならず、誤った大きさを渡すと未定義動作になり、クラッシュやメモリリークを起こすことがあります。 [feature#21861]
