    function rb_str_resize

    [edit]
    VALUE rb_str_resize(VALUE str, rb_len_t len)

    文字列 str の長さを len バイトにします。 rb_str_set_len と異なり、文字列を伸ばすこともできます。 len が元の長さより小さければ、len バイトより後ろの内容は捨てられます。大きければ、元の長さより後ろの内容は保証されず、ごみになります。

    この関数を呼ぶと RSTRING_PTR(str) が変わることがあります。 str は String でなければいけません。

    [PARAM] str:
    長さを変える String です。
    [PARAM] len:
    新しい長さです。
    [RETURN]
    引数の str です。
    [EXCEPTION] ArgumentError:
    len が負のとき。
    [EXCEPTION] RuntimeError:
    str が locktmp されているとき。
    [EXCEPTION] FrozenError:
    str が凍結されているとき。
