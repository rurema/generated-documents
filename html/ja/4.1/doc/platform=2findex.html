    Ruby が動作するプラットフォーム

    [edit]

    Ruby は様々な環境で動作するよう各方面の有志によって移植されています。以下、Ruby の動作環境について OS や開発環境で大別して説明します。プラットフォームごとの保守担当者 (platform maintainer) の一覧は Ruby のソースツリーの doc/maintainers.md にあります。mswin64、mingw32 (MinGW)、AIX、FreeBSD、Solaris、RHEL/CentOS、macOS、OpenBSD、WebAssembly/WASI には担当者がいて、Cygwin にはいません。

    インストールやコンパイルに関しては、「Rubyのインストール」(https://www.ruby-lang.org/ja/documentation/installation/)を参照。

    • Unix
    • Win32
      • Win32ネイティブ版
        • mswin32
        • MinGW, mingw32
      • Cygwin
    • Mac OS X
    • GNU, GNU Hurd

    WebAssembly/WASI

    Ruby 3.2 で WebAssembly/WASI がサポート対象のプラットフォームに加わりました。詳細は Ruby のソースツリーの wasm/README.md と ruby.wasm (https://github.com/ruby/ruby.wasm) を参照してください。[feature#18462]
