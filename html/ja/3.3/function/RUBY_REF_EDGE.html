    macro RUBY_REF_EDGE

    [edit]
    size_t RUBY_REF_EDGE(type, member)

    構造体 type のメンバ member を、VALUE への参照(edge)として宣言します。 RUBY_REFERENCES のブロックの中で使います。値は構造体の先頭から member までのオフセットです。

    使い方は RUBY_REFERENCES を参照してください。

    [PARAM] type:
    構造体の型です。
    [PARAM] member:
    構造体の中の VALUE を持つメンバの名前です。
    [RETURN]
    member のオフセットです。
