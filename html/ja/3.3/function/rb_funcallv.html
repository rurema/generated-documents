    3. rb_funcallv

    function rb_funcallv

    [edit]
    VALUE rb_funcallv(VALUE recv, ID mid, int argc, const VALUE *argv)

    recv のメソッド mid を、引数を C の配列で渡して呼び出します。 private や protected のメソッドも呼び出せます。 rb_funcall とは、引数の渡し方だけが異なります。

    [PARAM] recv:
    メソッドのレシーバです。
    [PARAM] mid:
    呼び出すメソッドの名前です。
    [PARAM] argc:
    argv の要素数です。
    [PARAM] argv:
    メソッドに渡す引数の配列です。
    [RETURN]
    呼び出したメソッドの返り値です。
    [EXCEPTION] NoMethodError:
    メソッドがないとき。
    [EXCEPTION] Exception:
    呼び出したメソッドの中で例外が発生したとき。
