    module function Prism.#dump

    dump(source, **options) -> StringRuby 3.3 から[permalink][rdoc][edit]

    source を構文解析した結果を prism 独自のバイナリ形式にシリアライズし、その文字列を返します。この形式は主に、CRuby の拡張ライブラリを経由せずに、他言語(JavaScript、Rust、Java など)の実装から prism の構文木を読み込むために使われます。エンコーディングは常に ASCII-8BIT (BINARY) になります。オプションは Prism.#parse と同じです。

    [PARAM] source:
    解析する Ruby プログラムの文字列を指定します。
    [PARAM] options:
    Prism.#parse を参照してください。
    例 
    require "prism"

dumped = Prism.dump("1 + 2")
p dumped.class     # => String
p dumped.encoding  # => #<Encoding:BINARY (ASCII-8BIT)>
