    instance method Prism::Node#set_newline_flag

    set_newline_flag(newline_marked) -> ()Ruby 3.3 から Ruby 3.4 で削除[permalink][rdoc][edit]

    このノードの開始行にまだ印が付けられていなければ、Prism::Node#newline? が true を返すように印を付けます。

    newline_marked は行番号をインデックスとする真偽値の配列です。Prism::ParseResult#mark_newlines! が構文木を巡回する際に、行ごとに最初に見つかったノードだけに印を付けるために内部で使用します。

    [PARAM] newline_marked:
    行番号をインデックスとする真偽値の配列を指定します。すでに印が付いている行には true が入っています。
