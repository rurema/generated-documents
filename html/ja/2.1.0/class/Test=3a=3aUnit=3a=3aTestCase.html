    要約

    テストの基本単位(あるいは「テスト本体」)を表すクラスです。テストを行うメソッド(テストメソッド)は TestCase のサブクラスのインスタンスメソッドとして定義されます。テストメソッドの名前は「test」で始まっていなければなりません。逆に、「test」で始まっているメソッドは全てテストメソッドと見なされます。 

    require 'test/unit'

class TC_String < Test::Unit::TestCase
  def test_size
    assert_equal('abc'.size, 3)
  end

  def test_concat
    assert_raise(TypeError) do
      'abc' + 1
    end
  end
end

    各 TestCase オブジェクトは、ひとつのテストメソッドに対応しています。テストが実行される時には、テストメソッドの数だけ TestCase オブジェクトが生成されます。
