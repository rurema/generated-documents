    instance method Object#instance_variables

    instance_variables -> [Symbol][permalink][rdoc]

    オブジェクトのインスタンス変数名をシンボルの配列として返します。 

    obj = Object.new
obj.instance_eval { @foo, @bar = nil }
p obj.instance_variables

#=> [:@foo, :@bar]
