    macro NUM2ULL

    [edit]
    unsigned long long NUM2ULL(VALUE x)

    Numeric のオブジェクト x を、C の unsigned long long に変換します。

    [PARAM] x:
    変換する数値のオブジェクトです。
    [RETURN]
    unsigned long long に変換した値です。
    [EXCEPTION] TypeError:
    x が数値でないとき。
    [EXCEPTION] RangeError:
    x が unsigned long long で表せる範囲外のとき。
