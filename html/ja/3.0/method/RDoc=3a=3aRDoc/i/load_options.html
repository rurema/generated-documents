    instance method RDoc::RDoc#load_options

    load_options -> RDoc::OptionsRuby 2.0.0 から Ruby 3.1 で削除[permalink][rdoc][edit]

    カレントディレクトリの .rdoc_options ファイルが存在すれば、その内容を読み込んで RDoc::Options オブジェクトを返します。存在しない場合は新しい RDoc::Options オブジェクトを返します。

    [EXCEPTION] RDoc::Error:
    .rdoc_options ファイルの内容が正しい RDoc::Options の形式でなかった場合に発生します。

    [SEE_ALSO] RDoc::Options#write_options
