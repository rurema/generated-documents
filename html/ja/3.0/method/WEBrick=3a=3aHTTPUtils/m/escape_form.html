    module function WEBrick::HTTPUtils.#escape_form

    escape_form(str) -> StringRuby 3.0 から[permalink][rdoc][edit]

    与えられた文字列を application/x-www-form-urlencoded 形式の文字列に変換します。スペースは + に変換されます。

    [PARAM] str:
    文字列を指定します。 
    require 'webrick'
p WEBrick::HTTPUtils.escape_form('foo bar+baz')  # => "foo+bar%2Bbaz"

    [SEE_ALSO] WEBrick::HTTPUtils.#unescape_form
