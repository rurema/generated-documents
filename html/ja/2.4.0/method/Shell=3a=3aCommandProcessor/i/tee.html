    instance method Shell::CommandProcessor#tee

    tee(file) -> Shell::Filter[permalink][rdoc]

    実行すると, それらを内容とする Filter オブジェクトを返します.

    [PARAM] file:
    シェルコマンドtee に与えるファイル名を文字列で指定します。

    動作例 

    require 'shell'
Shell.def_system_command("head")
sh = Shell.new
sh.transact {
  glob("*.txt").to_a.each { |file|
    file.chomp!
    cat(file).each { |l|
      echo(l) | tee(file + ".tee") >> "all.tee"
    }
  }
}
