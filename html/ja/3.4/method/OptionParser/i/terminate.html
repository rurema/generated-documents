    instance method OptionParser#terminate

    terminate(arg = nil) -> ()Ruby 3.0 から[permalink][rdoc][edit]

    オプションのパースを打ち切ります。

    arg を指定すると、パースされずに残った引数の先頭に arg を戻します。オプションを処理するブロックの中から呼び出し、その時点でパースを終了させたい場合に使います。

    内部では OptionParser.terminate を呼び出しています。

    [PARAM] arg:
    パース結果の先頭に戻す文字列を指定します。省略した場合は何も戻しません。 
    require "optparse"

opts = OptionParser.new
opts.on("-a"){ |v| }
opts.on("-b"){ |v| opts.terminate("leftover") }
p opts.parse(["-b", "-a"])   # => ["leftover", "-a"]
