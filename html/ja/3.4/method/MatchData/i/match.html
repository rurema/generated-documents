    instance method MatchData#match

    match(n) -> String | nilRuby 3.1 から[permalink][rdoc][edit]
    match(name) -> String | nil

    n 番目、または name という名前のグループにマッチした部分文字列を返します。

    MatchData#[] と似ていますが、範囲や複数要素の指定はできず、単一のグループに対応する部分文字列だけを返します。マッチしていないグループを指定した場合は nil を返します。

    [PARAM] n:
    返す部分文字列のインデックスを 0 以上の整数で指定します。 0 はマッチ全体を意味します。
    [PARAM] name:
    名前付きグループの名前を String か Symbol で指定します。
    [EXCEPTION] IndexError:
    範囲外の n や、存在しない name を指定した場合に発生します。
    例 
    m = /(.)(.)(\d+)(\d)(\w)?/.match("THX1138.")
p m.match(0) # => "HX1138"
p m.match(4) # => "8"
p m.match(5) # => nil

m = /(?<foo>.)(.)(?<bar>.+)/.match("hoge")
p m.match(:foo) # => "h"
p m.match(:bar) # => "ge"
