    instance method Prism::ParseResult#mark_newlines!

    mark_newlines! -> ()Ruby 3.3 から[permalink][rdoc][edit]

    構文木を巡回し、CRuby の :line TracePoint イベントが発生する行に対応するノードに印を付けます。

    印が付いたノードは Prism::Node#newline? で判定できます。Prism.#parse などの通常の解析結果ではこの処理は解析時にすでに行われていますが、構文木を独自に構築した場合など、印が付いていない構文木に対して明示的に呼び出すために使います。

    例 
    require "prism"

result = Prism.parse("if true\n  1\nend\n")
result.mark_newlines!
p result.value.statements.body[0].newline?
# => true
