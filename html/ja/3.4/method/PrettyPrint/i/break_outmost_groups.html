    instance method PrettyPrint#break_outmost_groups

    break_outmost_groups -> ()[permalink][rdoc][edit]

    自身のバッファの中で、出力幅(PrettyPrint#maxwidth)を超えている外側のグループを、バッファの幅が maxwidth 以下になるまで改行して出力します。

    PrettyPrint#text や PrettyPrint#breakable の内部で、バッファに追加を行うたびに呼ばれています。 

    require 'prettyprint'

out = PrettyPrint.format(''.dup, 10) do |q|
  q.text 'aaaaa'
  q.group {
    q.text 'b' * 20
    q.breakable
    q.text 'c'
  }
  q.break_outmost_groups
  q.text 'd'
end
puts out
# => aaaaabbbbbbbbbbbbbbbbbbbb
