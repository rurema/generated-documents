    module function Math.#gamma

    gamma(x) -> FloatRuby 1.9.3 から[permalink][rdoc][edit]

    x のガンマ関数の値を返します。

    [PARAM] x:
    実数
    [EXCEPTION] TypeError:
    x に数値以外を指定した場合に発生します。
    [EXCEPTION] Math::DomainError:
    x に負の整数、もしくは -∞ を渡した場合に発生します。
    [EXCEPTION] RangeError:
    x に実数以外の数値を指定した場合に発生します。
    自然数 𝑛 に対し Γ(𝑛) = (𝑛 - 1)! を確認 
    def fact(n) = (1..n).inject(1, :*) # 階乗

1.upto(18) { |n| p [n, Math.gamma(n), fact(n - 1)] }

    x に符号付きゼロを渡した場合も +0.0 と -0.0 は区別され、符号付きの無限大を返します。これは x に負の整数を渡した場合に Math::DomainError が発生するのとは別の挙動です。

    例: 符号付きゼロ 
    p Math.gamma(0.0)   # =>  Infinity
p Math.gamma(-0.0)  # => -Infinity
