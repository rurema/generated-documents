    instance method Net::IMAP::Config#load_defaults

    load_defaults(version) -> selfRuby 3.4 から[permalink][rdoc][edit]

    debug 以外の属性に version の版の既定値を設定して self を返します。

    継承元は変わりません。設定した属性は継承元から継承しなくなります。 version は Net::IMAP::Config.[] と同じように、版の数値や名前で指定します。

    [PARAM] version:
    版の数値か名前
    [EXCEPTION] ArgumentError:
    version が数値でもシンボルでも文字列でもない場合に発生します。
    [EXCEPTION] RangeError:
    未知の版の数値を指定した場合に発生します。
    [EXCEPTION] KeyError:
    未知の名前を指定した場合に発生します。
    [EXCEPTION] TypeError:
    文字列を指定した場合に発生します。
    例 
    require 'net/imap'

config = Net::IMAP::Config.new(debug: true)
config.load_defaults(0.4)
p config.enforce_logindisabled              # => false
p config.responses_without_block            # => :silence_deprecation_warning
p config.debug                              # => true
p config.inherited?(:enforce_logindisabled) # => false
