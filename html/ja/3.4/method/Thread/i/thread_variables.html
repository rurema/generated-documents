    instance method Thread#thread_variables

    thread_variables -> [Symbol]Ruby 3.0 から[permalink][rdoc][edit]

    スレッドローカル変数の名前を Symbol の配列で返します。

    [注意]: Thread#[] でセットしたローカル変数(Fiber ローカル変数)は対象ではない事に注意してください。

    例 
    thr = Thread.new do
  Thread.current.thread_variable_set(:cat, 'meow')
  Thread.current.thread_variable_set("dog", 'woof')
end
thr.join
p thr.thread_variables # => [:cat, :dog]
