    module function Zlib.#gzip

    gzip(string, level: nil, strategy: nil) -> StringRuby 2.4.0 から[permalink][rdoc][edit]

    string を gzip 形式に圧縮した文字列を返します。

    [PARAM] string:
    圧縮する文字列を指定します。
    [PARAM] level:
    圧縮の水準を整数で指定します。有効な値は Zlib::NO_COMPRESSION, Zlib::BEST_SPEED, Zlib::BEST_COMPRESSION, Zlib::DEFAULT_COMPRESSION (デフォルト) 及び 0 から 9 の整数です。
    [PARAM] strategy:
    圧縮方法を整数で指定します。有効な値は Zlib::FILTERED, Zlib::HUFFMAN_ONLY, Zlib::DEFAULT_STRATEGY (デフォルト) 等です。Zlib::Deflate.new を参照してください。 
    require 'zlib'

compressed = Zlib.gzip('hoge fuga')
p Zlib.gunzip(compressed) # => "hoge fuga"
