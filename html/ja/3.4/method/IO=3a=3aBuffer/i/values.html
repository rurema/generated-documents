    instance method IO::Buffer#values

    values(buffer_type, offset = 0, count = nil) -> [Integer | Float]Ruby 3.2 から[permalink][rdoc][edit]

    バッファの offset の位置から、buffer_type で指定した型の値を順に読み出し、配列にして返します。

    指定できる型は IO::Buffer#get_value を参照してください。

    [PARAM] buffer_type:
    読み出す値の型をシンボルで指定します。
    [PARAM] offset:
    読み出しを開始する位置をバッファの先頭からのバイト数で指定します。
    [PARAM] count:
    読み出す個数を指定します。省略した場合はバッファの末尾まで読み出します。 
    buf = IO::Buffer.for("Hello World")
p buf.values(:U8, 2, 2) # => [108, 108]
p buf.values(:U8, 9)    # => [108, 100]
