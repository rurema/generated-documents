# class Rinda::SimpleRenewer < Object

シンプルな renewer で renewer のサンプル実装です。

[Rinda::TupleSpace](../class/Rinda=3a=3aTupleSpace.md) が保持するタプルの有効期限を更新するクラスです。
このクラスはタプルの寿命をプロセスの寿命と一致させることができます。
詳しくは [Rinda::TupleSpace#renewer](../class/Rinda=3a=3aTupleSpace.md#renewer) を見てください。
