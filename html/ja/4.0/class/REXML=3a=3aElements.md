# class REXML::Elements < Object

要素の集合を表すクラスです。

XPath による探索をサポートします。

[REXML::Element#elements](../method/REXML=3a=3aElement/i/elements.md) はこのオブジェクトを返します。
XPath で相対パスを指定した場合は、この REXML::Element#elements のレシーバが基準要素となります。
