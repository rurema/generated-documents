# class Net::FTP::MLSxEntry < Object

[Net::FTP#mlsd](../method/Net=3a=3aFTP/i/mlsd.md)、[Net::FTP#mlst](../method/Net=3a=3aFTP/i/mlst.md) の結果を保持するクラスです。

### Notes

このクラスのオブジェクトが保持している permission の情報
([Net::FTP::MLSxEntry#deletable?](../method/Net=3a=3aFTP=3a=3aMLSxEntry/i/deletable=3f.md) など)は対応するコマンド([Net::FTP#delete](../method/Net=3a=3aFTP/i/delete.md) など)が常にうまくいくことを保証するものではありません。
例えばディスクの空き容量が不足しているというような理由でうまくいかない場合があります。
