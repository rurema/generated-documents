# module File::Constants

[File](../class/File.md) に関る定数を集めたモジュール。

[File](../class/File.md) はこのモジュールをインクルードしているので、以下に挙げる定数は [File](../class/File.md) の定数のように扱うことができます。

Ruby 1.8 以降では、[File](../class/File.md) ではなく、[IO](../class/IO.md) でインクルードされるようになりました。
