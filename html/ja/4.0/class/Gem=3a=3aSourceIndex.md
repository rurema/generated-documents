# class Gem::SourceIndex < Object

個々のソースから取得した全ての有効な Gem パッケージをインデックス化するためのクラスです。

Gem パッケージのフルネームと それぞれの [Gem::Specification](../class/Gem=3a=3aSpecification.md) オブジェクトを対応付けます。
