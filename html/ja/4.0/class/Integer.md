# class Integer < Numeric

整数クラスです。

整数オブジェクトに特異メソッドを追加する事はできません。追加した場合、
[TypeError](../class/TypeError.md) が発生します。

かつて `Integer` クラスのエイリアスであった `Fixnum` と `Bignum` は Ruby 3.2 で削除されました。
