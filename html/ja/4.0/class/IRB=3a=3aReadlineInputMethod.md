# class IRB::ReadlineInputMethod < IRB::StdioInputMethod

readline を用いた標準入力からの入力を表すクラスです。ライブラリ内部で使用します。
[readline](../library/readline.md) の require に失敗した場合は、[Reline](../class/Reline.md) が代わりに使われます。
