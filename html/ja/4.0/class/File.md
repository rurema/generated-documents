# class File < IO

ファイルアクセスのためのクラスです。

通常 [Kernel?.open](../method/Kernel/m/open.md) または [File.open](../method/File/s/open.md) を使って生成します。
[IO](../class/IO.md) クラスがインクルードしている [File::Constants](../class/File=3a=3aConstants.md) は File クラスに関係する定数を格納したモジュールです。
また [File::Stat](../class/File=3a=3aStat.md) は stat 構造体( [man:stat(2)] 参照)を表すクラスです。
