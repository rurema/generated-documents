# class REXML::Attribute < Object

要素([REXML::Element](../class/REXML=3a=3aElement.md))の属性を表すクラスです。

つまり、 <element attribute="value"/> という要素における attribute=value というペアのことです。

属性にはなんらかの名前空間(namespace, [REXML::Namespace](../class/REXML=3a=3aNamespace.md))
に属せます。
