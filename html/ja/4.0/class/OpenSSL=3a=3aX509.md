# module OpenSSL::X509

OpenSSL の X509 証明書、CRL(証明書失効リスト)、
CSR(証明書署名要求)、証明書ストアなどに関するモジュールです。

### 検証時エラー定数 {#verify_error}

以下の定数は [OpenSSL::X509::Store#error](../method/OpenSSL=3a=3aX509=3a=3aStore/i/error.md),
[OpenSSL::X509::StoreContext#error](../method/OpenSSL=3a=3aX509=3a=3aStoreContext/i/error.md),
[OpenSSL::SSL::SSLSocket#verify_result](../method/OpenSSL=3a=3aSSL=3a=3aSSLSocket/i/verify_result.md)
の返り値として用いられます。
V_OK はエラーなしを意味しています。
