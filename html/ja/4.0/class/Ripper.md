# class Ripper < Object

Ruby プログラムのパーサです。

Ruby プログラムをテキストとして扱いたい場合、例えばソース色付けを行いたい場合は、
[Ripper::Filter](../class/Ripper=3a=3aFilter.md) クラスを使うとよいでしょう。
