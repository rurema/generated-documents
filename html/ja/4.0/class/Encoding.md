# class Encoding < Object

文字エンコーディング(文字符号化方式)のクラスです。Rubyの多言語対応(M17N)機能において利用されます。

例えば文字列オブジェクトは、文字列のバイト表現の他にそのバイト表現がどのエンコーディングによるものであるかも併せて保持しています。この情報は [String#encoding](../method/String/i/encoding.md) により取得できます。 Encoding オブジェクトを返すメソッドにはこの他に [IO#internal_encoding](../method/IO/i/internal_encoding.md), [IO#external_encoding](../method/IO/i/external_encoding.md) などがあります。

- **SEE** [spec/m17n](../doc/spec=2fm17n.md)
