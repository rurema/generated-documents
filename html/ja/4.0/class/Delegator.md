# class Delegator < Object

サブクラスにメソッド委譲の仕組みを提供する抽象クラス。

メソッド委譲を行う場合は、本クラスを継承し[Delegator#__getobj__](../method/Delegator/i/__getobj__.md)を再定義する必要があります。

具体的な使用例については、[SimpleDelegator](../class/SimpleDelegator.md)を参照してください。
