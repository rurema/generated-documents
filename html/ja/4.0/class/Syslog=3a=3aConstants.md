# module Syslog::Constants

このモジュールにはシステムで使用可能なLOG_*定数、モジュール関数が定義されています。

```ruby title="例"
require 'syslog'
include Syslog::Constants
```

それぞれの定数、モジュール関数は以下のモジュールに分けて定義されています。

- [Syslog::Option](../class/Syslog=3a=3aOption.md)
- [Syslog::Facility](../class/Syslog=3a=3aFacility.md)
- [Syslog::Level](../class/Syslog=3a=3aLevel.md)
- [Syslog::Macros](../class/Syslog=3a=3aMacros.md)
