# class Resolv::DNS::Resource::HINFO < Resolv::DNS::Resource

DNS リソースの HINFO レコードを表す抽象クラスです。

このレコードはホストのハードウェアとソフトウェアの情報を保持しています。

[Resolv::DNS#getresource](../method/Resolv=3a=3aDNS/i/getresource.md) で HINFO レコードを得たい場合は
[Resolv::DNS::Resource::IN::HINFO](../class/Resolv=3a=3aDNS=3a=3aResource=3a=3aIN=3a=3aHINFO.md) を使うべきです。
