# class RDoc::Markup::Formatter < Object

RDoc 形式のドキュメントを整形するための基本クラスです。

実際にドキュメントを整形するには、[RDoc::Markup::ToHtml](../class/RDoc=3a=3aMarkup=3a=3aToHtml.md) のような、継承したクラスで convert メソッドを実行してください。
