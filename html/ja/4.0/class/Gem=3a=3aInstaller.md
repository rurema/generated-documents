# class Gem::Installer < Object

[Gem::Installer](../class/Gem=3a=3aInstaller.md) は Gem を展開し、  Gem に含まれていたファイルをファイルシステム上の正しい位置に配置します。

また、gemspec を specifications ディレクトリに、キャッシュを cache ディレクトリに、実行ファイルやシンボリックリンクなどを bin ディレクトリに配置します。
