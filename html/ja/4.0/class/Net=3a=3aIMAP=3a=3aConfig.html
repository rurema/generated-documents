    class Net::IMAP::Config

    [edit]
    クラス・モジュールの継承リスト:
    1. BasicObject
    2. Kernel
    3. Object
    4. Net::IMAP::Config

    要約

    Net::IMAP の動作の設定を表すクラスです。

    全体の設定は Net::IMAP.config または Net::IMAP::Config.global で、接続ごとの設定は Net::IMAP#config で得られます。 Net::IMAP.new は、config で指定した設定(省略時は全体の設定)を継承元とする接続ごとの設定を作り、残りのキーワード引数をその初期値にします。

    各設定は継承元(Net::IMAP::Config#parent で得られます)を持ち、自身で値を設定していない属性は継承元の値を返します。継承元の値は参照するたびに調べるので、継承元の値を変えると、それを継承している設定にもすぐに反映されます。既定では、接続ごとの設定は全体の設定を、全体の設定は Net::IMAP::Config.default を継承します。

    継承の例 
    require 'net/imap'

parent = Net::IMAP::Config.new(open_timeout: 10)
config = parent.new(idle_response_timeout: 3)
p config.open_timeout              # => 10
p config.inherited?(:open_timeout) # => true
parent.open_timeout = 20
p config.open_timeout              # => 20
p config.idle_response_timeout     # => 3

    Net::IMAP.new の config に net-imap の版の数値(0.4 など)を渡すと、その版の既定値を使えます。版ごとの既定値は Net::IMAP::Config.[] で得られる凍結済みの設定で、その継承元は全体の設定です。ただし debug は版ごとの既定値に含まれず、全体の設定から継承します。版の数値のかわりに、次の名前も使えます。

    • :current は、現在の版の既定値です。
    • :default は、:current と同じです。Net::IMAP::Config.default とは別のオブジェクトで、debug を全体の設定から継承します。
    • :next は、次の版で予定している既定値です。
    • :future は、将来の版で予定している既定値です。
    • :original は、版の数値 0.0 と同じで、設定の仕組みが入る前の動作に合わせた既定値です。
    版ごとの既定値の例 
    require 'net/imap'

p Net::IMAP::Config[0.3].sasl_ir                 # => false
p Net::IMAP::Config[0.4].sasl_ir                 # => true
p Net::IMAP::Config[0.4].responses_without_block # => :silence_deprecation_warning
p Net::IMAP::Config[0.4].frozen?                 # => true
Net::IMAP.debug = true
p Net::IMAP::Config[0.4].debug                   # => true

    既にある設定の属性をある版の既定値にするには Net::IMAP::Config#load_defaults を使います。

    設定の変更はスレッド間で同期されません。

    特異メソッド

    self[config] -> Net::IMAP::ConfigRuby 3.4 から[permalink][rdoc][edit]

    config に対応する設定を返します。

    config には次のものを指定できます。

    • Net::IMAP::Config オブジェクトを指定すると、それをそのまま返します。
    • ハッシュ(to_hash に応答するオブジェクト)を指定すると、その内容を属性の値とし、全体の設定を継承元とする凍結済みの新しい設定を返します。
    • 版の数値(0.4 など)を指定すると、その版の既定値の設定を返します。
    • 名前(:current など)を指定すると、その名前の既定値の設定を返します。
    • 文字列("0.5" など)を指定すると、版の数値や名前に変換して、その既定値の設定を返します。

    版の数値や名前で得られる設定は凍結済みで、継承元は全体の設定です。

    [PARAM] config:
    設定、ハッシュ、版の数値、名前のいずれか
    [EXCEPTION] RangeError:
    未知の版の数値を指定した場合に発生します。
    [EXCEPTION] KeyError:
    未知の名前(シンボルか文字列)を指定した場合に発生します。
    [EXCEPTION] TypeError:
    上記以外のもの(nil など)を指定した場合に発生します。
    例 
    require 'net/imap'

config = Net::IMAP::Config[{open_timeout: 1}]
p config.open_timeout # => 1
p config.frozen?      # => true
p Net::IMAP::Config[Net::IMAP::Config.default].equal?(Net::IMAP::Config.default) # => true

    [SEE_ALSO] Net::IMAP::Config.version_defaults, Net::IMAP::Config.new

    new(parent = Net::IMAP::Config.global, **attrs) -> Net::IMAP::ConfigRuby 3.4 から[permalink][rdoc][edit]
    new(parent = Net::IMAP::Config.global, **attrs) {|config| ... } -> Net::IMAP::Config

    parent を継承元とする新しい設定を作り、attrs で属性の値を設定して返します。

    parent は Net::IMAP::Config.[] で変換するので、設定のほかに版の数値や名前やハッシュも指定できます。ブロックを渡すと、作った設定をブロックに渡してから返します。

    [PARAM] parent:
    継承元の設定。省略時は全体の設定
    [PARAM] attrs:
    設定する属性の名前と値
    [EXCEPTION] ArgumentError:
    attrs に未知の属性名がある場合や、属性に不正な値を指定した場合に発生します。
    [EXCEPTION] TypeError:
    parent に設定に変換できないもの(nil など)を指定した場合に発生します。
    例 
    require 'net/imap'

config = Net::IMAP::Config.new(open_timeout: 10)

p config.parent.equal?(Net::IMAP::Config.global) # => true
p Net::IMAP::Config.new(0.3).sasl_ir             # => false

    enforce_logindisabled -> Symbol | boolRuby 3.4 から[permalink][rdoc][edit]

    Net::IMAP#login の前に、サーバの機能一覧に LOGINDISABLED があるかを確認するかどうかを返します。

    確認して LOGINDISABLED があったときは、LOGIN コマンドを送らずに Net::IMAP::LoginDisabledError が発生します。値の意味は次のとおりです。

    • false のときは、確認せずに LOGIN コマンドを送ります。
    • :when_capabilities_cached のときは、サーバの機能一覧を取得済みのときだけ確認し、機能一覧を調べるための CAPABILITY コマンドは送りません。
    • true のときは、確認します。機能一覧が未取得なら、LOGIN コマンドの前に CAPABILITY コマンドを送ります。

    既定値は true です。版ごとの既定値は、0.4 以前が false、0.5 以降が true です。

    [SEE_ALSO] Net::IMAP::Config#enforce_logindisabled=, Net::IMAP#login

    max_response_size -> Integer | nilRuby 4.0 から[permalink][rdoc][edit]

    サーバの応答 1 つの大きさの上限(バイト数)を返します。

    nil は上限がないことを表します。応答の大きさが上限に達するか、リテラルを読むと上限を超えるときは、Net::IMAP::ResponseTooLargeError が発生して接続を閉じます。この上限は応答 1 つごとのもので、応答の数や、記録される未処理の応答の量は制限しません。既定値は 536870912(512 MiB)で、信頼できないサーバに接続するときはもっと小さい値にするべきです。版ごとの既定値は、0.4 以前が nil、0.5 以降が 536870912 です。

    値を変えてもすぐには反映されないことがあります。受信スレッドが前の値で次の応答を待っていることがあるためで、Net::IMAP#noop などで応答を受け取ると新しい値が使われます。

    [SEE_ALSO] Net::IMAP::Config#max_response_size=, Net::IMAP#max_response_size

    responses_without_block -> SymbolRuby 3.4 から[permalink][rdoc][edit]

    Net::IMAP#responses を type もブロックも渡さずに呼んだときの動作を返します。

    値の意味は次のとおりです。

    • :silence_deprecation_warning のときは、警告を出さずに記録のハッシュそのものを返します。
    • :warn のときは、非推奨の警告を出して記録のハッシュそのものを返します。
    • :frozen_dup のときは、記録のハッシュを凍結した複製(値の配列も凍結したもの)を返します。
    • :raise のときは、ArgumentError が発生します。

    記録のハッシュそのものを扱うのはスレッド安全ではありません。

    既定値は :frozen_dup です。

    版ごとの既定値は、0.4 以前が :silence_deprecation_warning、0.5 が :warn、0.6 以降が :frozen_dup です。

    sasl_ir -> Symbol | boolRuby 3.4 から[permalink][rdoc][edit]
    sasl_ir? -> Symbol | bool

    Net::IMAP#authenticate で SASL-IR 拡張([RFC4959])を使うかどうかを返します。

    サーバと認証方式の両方が SASL-IR 拡張に対応しているときに使います。 Net::IMAP#authenticate で sasl_ir を指定すると、そちらが優先されます。

    値の意味は次のとおりです。

    • false のときは、SASL-IR 拡張を使いません。
    • :when_capabilities_cached のときは、サーバの機能一覧を取得済みのときだけ SASL-IR 拡張を使い、機能一覧を調べるための CAPABILITY コマンドは送りません。
    • true のときは、SASL-IR 拡張を使います。

    既定値は true です。版ごとの既定値は、0.3 以前が false、0.4 以降が true です。
