# module Marshal

Ruby オブジェクトをファイル(または文字列)に書き出したり、読み戻したりする機能を提供するモジュール。

大部分のクラスのインスタンスを書き出す事ができますが、書き出しの不可能なクラスも存在します([Marshal?.dump](../method/Marshal/m/dump.md) を参照)。

ここで「マーシャルデータ」と言う用語は、[Marshal?.dump](../method/Marshal/m/dump.md) が出力する文字列を指すものとします。
