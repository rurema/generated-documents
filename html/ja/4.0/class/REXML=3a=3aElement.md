# class REXML::Element < REXML::Parent

XML の要素(エレメント、element)を表すクラス。

要素は
  - 子要素(children)
  - 属性(attributes)
  - 名前(name)
を持つものとして特徴付けられます。

また、要素はある別の要素の子となることもできます。
