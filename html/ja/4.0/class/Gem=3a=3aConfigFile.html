    class Gem::ConfigFile

    [edit]
    クラス・モジュールの継承リスト:
    1. BasicObject
    2. Kernel
    3. Object
    4. Gem::ConfigFile

    要約

    設定ファイルに書かれている gem コマンドのオプションをオブジェクトに保存するためのクラスです。

    このクラスのインスタンスはハッシュのように振る舞います。

    self[key] -> objectRuby 1.9.3 から[permalink][rdoc][edit]

    引数で与えられたキーに対応する設定情報を返します。

    [PARAM] key:

    [PARAM] value:
    設定情報の値を指定します。
    api_keys -> {Symbol => String}Ruby 1.9.3 から[permalink][rdoc][edit]

    認証情報ファイルに保存されている API キーのハッシュを返します。

    キーは rubygems.org の場合は :rubygems、それ以外の場合はホスト名のシンボルで、値は API キーです。認証情報ファイル(Gem::ConfigFile#credentials_path)が無いときは、設定ファイルから読み込んだハッシュをそのまま返します。

    [SEE_ALSO] Gem::ConfigFile#credentials_path, Gem::ConfigFile#set_api_key

    エラー発生時にバックトレースを出力するかどうかを返します。

    真の場合はバックトレースを出力します。そうでない場合はバックトレースを出力しません。

    例

    set_api_key(host, api_key) -> ()Ruby 2.4.0 から[permalink][rdoc][edit]

    unset_api_key! -> Integer | falseRuby 2.5.0 から[permalink][rdoc][edit]

    認証情報ファイルが無ければ偽を返します。あれば削除して、削除したファイルの数(1)を返します。

    update_sources -> boolRuby 1.9.3 から[permalink][rdoc][edit]

    Gem::SourceInfoCache を毎回更新するかどうか設定します。

    verbose=(verbose_level)Ruby 1.9.3 から[permalink][rdoc][edit]

    ログの出力レベルをセットします。

    [PARAM] verbose_level:
    真偽値またはシンボルを指定します。
