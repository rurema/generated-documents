    class Process::Waiter

    [edit]
    クラス・モジュールの継承リスト:
    1. BasicObject
    2. Kernel
    3. Object
    4. Thread
    5. Process::Waiter

    要約

    Process.#detach が返す、子プロセスの終了を監視するスレッドを表すクラスです。

    Thread のサブクラスであり、監視している子プロセスのプロセス ID を保持しています。

    [SEE_ALSO] Process.#detach
