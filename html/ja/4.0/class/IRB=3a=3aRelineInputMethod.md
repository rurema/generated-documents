# class IRB::RelineInputMethod < IRB::StdioInputMethod

[reline](../library/reline.md) を用いた標準入力からの入力を表すクラスです。ライブラリ内部で使用します。

対話的な端末では、irb は通常この入力方式を使用します。Ruby 3.1 までは
`IRB::ReidlineInputMethod` という名前でした。
