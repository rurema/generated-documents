# class YAML::Store < PStore

[Marshal?.dump](../method/Marshal/m/dump.md) したバイナリ形式の代わりに YAML 形式でファイルに保存します。

使い方は [PStore](../class/PStore.md) とほとんど同じです。
インターフェースは [Hash](../class/Hash.md) に似ています。
