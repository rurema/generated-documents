# class Prism::ParseResult < Prism::Result

[Prism?.parse](../method/Prism/m/parse.md) や [Prism?.parse_file](../method/Prism/m/parse_file.md) などの戻り値のクラスです。
構文解析によって得られた構文木そのものに加えて、解析中に見つかったコメント・マジックコメント・エラー・警告などの付随情報をまとめて保持します。
