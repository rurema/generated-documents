# コマンド

Ruby では以下のコマンドが提供されます。

- **`erb`**:
  埋め込みRuby処理ツール。[erb](../library/erb.md) を参照。
- **`gem`**:
  Rubyのパッケージ管理ツール。[rubygems#gem_command](../library/rubygems.md#gem_command) を参照。
- **`irb`**:
  Ruby の対話インタフェース。[irb](../library/irb.md) を参照。
- **`rake`**:
  Ruby の内部 DSL で記述するビルドツール。[rake](../library/rake.md) を参照。
- **`rdoc`**:
  Ruby のソースファイルからドキュメントを生成するツール。[rdoc](../library/rdoc.md) を参照。
- **`ri`**:
  RDoc で書かれた Ruby のドキュメントをコマンドラインから閲覧するツール。
- **`ruby`**:
  Ruby 本体。[spec/rubycmd#ruby](../doc/spec=2frubycmd.md#ruby) を参照。

これらのコマンドは以下で説明される環境変数を参照します。

- [spec/envvars](../doc/spec=2fenvvars.md)
