# REXML::Parsers::PullEvent#[]

### def [](nth) -> object
### def [](start, len) -> [object]

イベントのパラメータを取り出します。

[Array#\[\]](../../../method/Array/i/=5b=5d.md) と同様の引数を取ります。

- **param** `nth` -- nth番目のイベントパラメータを取り出します
- **param** `start` -- start番目から len 個のイベントを取り出します
- **param** `len` -- start番目から len 個のイベントを取り出します
