# ENV.[]

### def ENV.[](key) -> String

key に対応する環境変数の値を返します。該当する環境変数が存在しない時には nil を返します。

- **param** `key` -- 環境変数名を指定します。文字列で指定します。文字列以外のオブジェクトを指定した場合は to_str メソッドによる暗黙の型変換を試みます。

```ruby
p ENV['PATH']         # => "/usr/local/bin:/usr/bin:/bin:/usr/X11/bin"
p ENV['NON_EXIST_KEY']  # => nil
```
