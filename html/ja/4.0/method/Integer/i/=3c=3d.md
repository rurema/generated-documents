# Integer#<=

### def <=(other) -> bool

数値として等しいまたは小さいか判定します。

`Integer` オブジェクトを左項とする比較演算子 `<=` はこのメソッドの呼び出しになります。

- **param** `other` -- 比較対象の数値
- **return** --      `self` よりも `other` の方が大きい場合か、
             両者が等しい場合 `true` を返します。
             そうでなければ `false` を返します。

```ruby
p 1 <= 0  # => false
p 1 <= 1  # => true
p 1 <= 2  # => true
```
