# Integer#<=>

### def <=>(other) -> -1 | 0 | 1 | nil

`self` を `other` と比較して、`self` のほうが大きいときに `1`、等しいときに `0`、小さいときに `-1`、比較できないときに `nil` を返します。

`Integer` オブジェクトを左項とする二項演算子 `<=>` はこのメソッドの呼び出しになります。

- **param** `other` -- 比較対象
- **return** --      `-1` か `0` か `1` か `nil` のいずれか

```ruby
p 1 <=> 2  # => -1
p 1 <=> 1  # => 0
p 2 <=> 1  # => 1
p 2 <=> '1' # => nil
```
