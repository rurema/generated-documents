# String#swapcase

### def swapcase(*options) -> String

大文字を小文字に、小文字を大文字に変更した文字列を返します。

- **param** `options` -- オプションの詳細は [String#downcase](../../../method/String/i/downcase.md) を参照してください。

```ruby title="例"
p "ABCxyz".swapcase   # => "abcXYZ"
p "Access".swapcase   # => "aCCESS"
```
