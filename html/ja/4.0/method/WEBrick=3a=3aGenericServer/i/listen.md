# WEBrick::GenericServer#listen

### def listen(address, port) -> [TCPServer]

与えられたアドレスとポートで [TCPServer](../../../class/TCPServer.md) オブジェクトを生成し
listener として管理します。

- **param** `address` -- アドレスを文字列で指定します。

- **param** `port` -- listen するポートを整数で指定します。

- **SEE** [WEBrick::GenericServer#listeners](../../../method/WEBrick=3a=3aGenericServer/i/listeners.md), [TCPServer#listen](../../../method/TCPServer/i/listen.md)
