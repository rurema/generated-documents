# OptionParser::Arguable#options=

### def options=(opt)

自身をパースするための [OptionParser](../../../class/OptionParser.md) オブジェクトをセットします。

- **param** `opt` -- 自身をパースする [OptionParser](../../../class/OptionParser.md) 、あるいは nil か false を指定します。
           nil か false である場合、自身の options= メソッドと options メソッドを
           undef します。
