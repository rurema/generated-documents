# RubyVM::YJIT.stats_string

### def RubyVM::YJIT.stats_string -> String

[RubyVM::YJIT.runtime_stats](../../../method/RubyVM=3a=3aYJIT/s/runtime_stats.md) の内容を人が読める形式に整形した文字列を返します。
`--yjit-stats` が有効なとき以外は空文字列を返します。
