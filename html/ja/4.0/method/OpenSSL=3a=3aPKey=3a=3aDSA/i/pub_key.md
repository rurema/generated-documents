# OpenSSL::PKey::DSA#pub_key

### def pub_key -> OpenSSL::BN

DSA 鍵の公開鍵パラメータを返します。

公開鍵はこの値と、
[OpenSSL::PKey::DSA#p](../../../method/OpenSSL=3a=3aPKey=3a=3aDSA/i/p.md), [OpenSSL::PKey::DSA#q](../../../method/OpenSSL=3a=3aPKey=3a=3aDSA/i/q.md), [OpenSSL::PKey::DSA#g](../../../method/OpenSSL=3a=3aPKey=3a=3aDSA/i/g.md)
から構成されます。
