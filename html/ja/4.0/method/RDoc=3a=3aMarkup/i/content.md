# RDoc::Markup#content

### def content -> String

変換する文字列を返します。

rdoc ライブラリのデバッグ用途に使用します。
[RDoc::Markup#convert](../../../method/RDoc=3a=3aMarkup/i/convert.md) の後に実行します。

変換のために加工したオブジェクトを改行で連結したものを返すため、変換前の文字列と結果が異なる事があります。

- **SEE** [RDoc::Markup#convert](../../../method/RDoc=3a=3aMarkup/i/convert.md)
