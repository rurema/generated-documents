# REXML::XMLDecl#==

### def ==(other) -> bool

self と other が同じであるならば真を返します。

「同じ」とは [REXML::XMLDecl#version](../../../method/REXML=3a=3aXMLDecl/i/version.md), [REXML::XMLDecl#encoding](../../../method/REXML=3a=3aXMLDecl/i/encoding.md),
[REXML::XMLDecl#standalone](../../../method/REXML=3a=3aXMLDecl/i/standalone.md) が一致していることを意味します。

- **param** `other` -- 比較対象のオブジェクト
