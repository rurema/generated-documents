# RDoc::CodeObject#document_children=

### def document_children=(val)

自身に含まれるメソッド、エイリアス、定数や属性をドキュメントに含めるかどうかを設定します。

:nodoc:、:stopdoc: を指定した時に false が設定されます。

- **param** `val` -- true を指定した場合、上記をドキュメントに含めます。
