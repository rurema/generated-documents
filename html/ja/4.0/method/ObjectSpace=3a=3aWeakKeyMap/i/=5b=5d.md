# ObjectSpace::WeakKeyMap#[]

### def [](key) -> object | nil

key に対応する値を返します。

key に対応する組が無い場合は nil を返します。

- **param** `key` -- 探すキーを指定します。等値性([Object#eql?](../../../method/Object/i/eql=3f.md))で比較されます。

```ruby
map = ObjectSpace::WeakKeyMap.new
key = "name"
map[key] = 1

p map["name"] # => 1
p map["zzz"]  # => nil
```
