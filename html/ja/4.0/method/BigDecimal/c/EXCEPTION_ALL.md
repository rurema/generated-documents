# BigDecimal::EXCEPTION_ALL

### const EXCEPTION_ALL -> Integer

[BigDecimal](../../../class/BigDecimal.md) の計算において例外を発生させるかどうかを設定、確認する際の値を返します。

以下の例外全てが対象です。

- [BigDecimal::EXCEPTION_INFINITY](../../../method/BigDecimal/c/EXCEPTION_INFINITY.md)
- [BigDecimal::EXCEPTION_NaN](../../../method/BigDecimal/c/EXCEPTION_NaN.md)
- [BigDecimal::EXCEPTION_OVERFLOW](../../../method/BigDecimal/c/EXCEPTION_OVERFLOW.md)
- [BigDecimal::EXCEPTION_UNDERFLOW](../../../method/BigDecimal/c/EXCEPTION_UNDERFLOW.md)
- [BigDecimal::EXCEPTION_ZERODIVIDE](../../../method/BigDecimal/c/EXCEPTION_ZERODIVIDE.md)

[BigDecimal.mode](../../../method/BigDecimal/s/mode.md) の第 1 引数に指定します。
