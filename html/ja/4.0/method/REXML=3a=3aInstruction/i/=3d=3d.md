# REXML::Instruction#==

### def ==(other) -> bool

other と self が同じ 処理命令である場合に真を返します。

同じとは、 [REXML::Instruction#target](../../../method/REXML=3a=3aInstruction/i/target.md) と [REXML::Instruction#content](../../../method/REXML=3a=3aInstruction/i/content.md)
が一致することを意味します。

- **param** `other` -- 比較対象
