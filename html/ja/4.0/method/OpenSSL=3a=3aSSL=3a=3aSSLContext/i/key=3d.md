# OpenSSL::SSL::SSLContext#key=

### def key=(key)

[OpenSSL::SSL::SSLContext#cert=](../../../method/OpenSSL=3a=3aSSL=3a=3aSSLContext/i/cert=3d.md) で設定された自分自身を証明するための証明書の公開鍵に対応する秘密鍵を設定します。

デフォルトは nil です。

- **param** `key` -- 設定する秘密鍵([OpenSSL::PKey::PKey](../../../class/OpenSSL=3a=3aPKey=3a=3aPKey.md) のサブクラスのインスタンス)
