# Benchmark::Tms#memberwise

### def memberwise(op, x) -> Benchmark::Tms

[Benchmark::Tms](../../../class/Benchmark=3a=3aTms.md) の四則演算を実行するために内部で使用されるメソッドです。

- **param** `op` -- 演算子をシンボルで与えます。
- **param** `x` -- [Benchmark::Tms](../../../class/Benchmark=3a=3aTms.md) のオブジェクトか [Float](../../../class/Float.md) に暗黙の変換ができるオブジェクトです。

- **return** -- 計算結果は新しい [Benchmark::Tms](../../../class/Benchmark=3a=3aTms.md) オブジェクトです。
