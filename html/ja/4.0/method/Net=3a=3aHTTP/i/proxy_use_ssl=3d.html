    instance method Net::HTTP#proxy_use_ssl=

    proxy_use_ssl=(ssl)Ruby 3.4 から[permalink][rdoc][edit]

    プロクシとの接続(プロクシ自身への TCP 接続)に SSL/TLS を使うかどうかを設定します。Net::HTTP#start で接続する前に設定する必要があります。

    これは、プロクシ経由で接続先自体に SSL/TLS を使うかどうかを指定する Net::HTTP#use_ssl= とは別の設定です。

    [PARAM] ssl:
    プロクシとの接続に SSL/TLS を使うかどうかを真偽値で指定します。
    例 
    require 'net/http'

http = Net::HTTP.new('www.example.com')
http.proxy_use_ssl = true
