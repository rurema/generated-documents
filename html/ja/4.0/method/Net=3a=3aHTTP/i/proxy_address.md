# Net::HTTP#proxy_address

### def proxy_address -> String|nil
### def proxyaddr -> String|nil

プロクシ経由で接続する HTTP オブジェクトならプロクシのアドレスを返します。

そうでないなら nil を返します。

proxyaddr は時代遅れのメソッドです。
