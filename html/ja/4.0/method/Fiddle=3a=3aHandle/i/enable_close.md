# Fiddle::Handle#enable_close

### def enable_close     -> nil

GC によるオブジェクトの回収時に self をクローズする([Fiddle::Handle#close](../../../method/Fiddle=3a=3aHandle/i/close.md))
ように設定します。

デフォルトでは close しません。
