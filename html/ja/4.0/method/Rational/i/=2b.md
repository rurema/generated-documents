# Rational#+

### def +(other) -> Rational | Float

和を計算します。

- **param** `other` -- `self` に足す数

`other` に [Float](../../../class/Float.md) を指定した場合は、計算結果を [Float](../../../class/Float.md) で返します。

```ruby title="例"
r = Rational(3, 4)
p r + Rational(1, 2)   # => (5/4)
p r + 1                # => (7/4)
p r + 0.5              # => 1.25
```
