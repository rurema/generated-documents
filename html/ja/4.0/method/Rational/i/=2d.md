# Rational#-

### def -(other) -> Rational | Float

`self` から `other` を引いた値（＝差）を返します。

`Rational` オブジェクトを左項とする算術演算子 `-` はこのメソッドの呼び出しになります。

- **param** `other` -- `self` から減算する数値

`other` に [Float](../../../class/Float.md) を指定した場合は、計算結果を [Float](../../../class/Float.md) で返します。

```ruby title="例"
r = Rational(3, 4)
p r - 1              # => (-1/4)
p r - 0.5            # => 0.25
```
