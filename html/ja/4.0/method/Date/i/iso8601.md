# Date#iso8601

### def iso8601 -> String

ISO 8601 書式の文字列を返します (拡大表記はつかいません)。
[Date#strftime](../../../method/Date/i/strftime.md) に `'%Y-%m-%d'` を指定した場合と同様、時刻を含まない日付のみの文字列になります。

```ruby title="例"
p Date.new(2001, 2, 3).iso8601 # => "2001-02-03"
```

- **SEE** [Date#rfc3339](../../../method/Date/i/rfc3339.md)
