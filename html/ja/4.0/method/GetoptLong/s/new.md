# GetoptLong.new

### def GetoptLong.new(*arguments)

GetoptLong のオブジェクトを生成します。引数が与えられたときは、それを [GetoptLong#set_options](../../../method/GetoptLong/i/set_options.md) メソッドに渡します。

- **param** `arguments` -- オプションを定義するための配列の配列を指定します。

- **SEE** [GetoptLong#set_options](../../../method/GetoptLong/i/set_options.md)
