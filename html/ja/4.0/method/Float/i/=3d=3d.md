# Float#==

### def ==(other) -> bool

`self` が数値として `other` と等しければ `true` を、そうでなければ `false` を返します。

`other` が数値でないときは `false` を返します。

`Float` オブジェクトを左項とする比較演算子 `==` はこのメソッドの呼び出しになります。

- **param** `other` -- 比較対象

```ruby title="例"
p 3.14 == 3.14000 # => true
p 3.14 == 3.1415  # => false
p 1.0 == "1" # => false
```

NaN 同士の比較は未定義です。

```ruby title="例"
p Float::NAN == Float::NAN    # => false
p [Float::NAN] == [Float::NAN]  # => true
p [Float::NAN] == [0.0 / 0.0] # => false
```
