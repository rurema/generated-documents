# Hash#>=

### def >=(other) -> bool

other が self のサブセットか同じである場合に真を返します。

- **param** `other` -- 自身と比較したい Hash オブジェクトを指定します。

```ruby title="例"
h1 = {a:1, b:2}
h2 = {a:1, b:2, c:3}
p h1 >= h2 # => false
p h2 >= h1 # => true
p h1 >= h1 # => true
```
