# Hash#<=

### def <=(other) -> bool

self が other のサブセットか同じである場合に真を返します。

- **param** `other` -- 自身と比較したい Hash オブジェクトを指定します。

```ruby title="例"
h1 = {a:1, b:2}
h2 = {a:1, b:2, c:3}
p h1 <= h2 # => true
p h2 <= h1 # => false
p h1 <= h1 # => true
```
