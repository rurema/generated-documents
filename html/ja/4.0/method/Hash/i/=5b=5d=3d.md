# Hash#[]=

### def []=(key, value)
### def store(key, value) -> object

key に対して value を関連づけます。value を返します。

- **param** `key` -- キーを指定します。
- **param** `value` -- 値を指定します。

```ruby title="例"
h = {}

h[:key] = "value"
p h #=>{:key => "value"}
```
