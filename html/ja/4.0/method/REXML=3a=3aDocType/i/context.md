# REXML::DocType#context

### def context -> { Symbol => object }

DTD が属する文書の「コンテキスト」を返します。

具体的には親ノードである [REXML::Document](../../../class/REXML=3a=3aDocument.md) オブジェクトの
[REXML::Element#context](../../../method/REXML=3a=3aElement/i/context.md) を返します。

コンテキストの具体的な内容については [REXML::Element#context](../../../method/REXML=3a=3aElement/i/context.md) を参照してください。
