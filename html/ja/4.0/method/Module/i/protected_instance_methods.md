# Module#protected_instance_methods

### def protected_instance_methods(inherited_too = true) -> [Symbol]

そのモジュールで定義されている protected メソッド名の一覧を配列で返します。

- **param** `inherited_too` -- false を指定するとそのモジュールで定義されているメソッドのみ返します。
