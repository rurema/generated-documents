# Socket.pair

### def Socket.pair(domain, type, protocol=0) -> Array
### def Socket.socketpair(domain, type, protocol=0) -> Array

相互に結合されたソケットのペアを含む2要素の配列を返します。
引数の指定は [Socket.open](../../../method/Socket/s/open.md) と同じです。

- **param** `domain` -- [Socket.open](../../../method/Socket/s/open.md) を参照してください。

- **param** `type` --   [Socket.open](../../../method/Socket/s/open.md) を参照してください。

- **param** `protocol` -- [Socket.open](../../../method/Socket/s/open.md) を参照してください。

- **SEE** [Socket.open](../../../method/Socket/s/open.md)
