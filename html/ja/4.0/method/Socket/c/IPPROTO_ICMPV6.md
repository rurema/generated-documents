# Socket::IPPROTO_ICMPV6

### const IPPROTO_ICMPV6 -> Integer

Internet Control Message Protocol for IPv6。
[BasicSocket#getsockopt](../../../method/BasicSocket/i/getsockopt.md), [BasicSocket#setsockopt](../../../method/BasicSocket/i/setsockopt.md) の 
level 引数に使用します。

また、[Socket.open](../../../method/Socket/s/open.md) の protocol 引数に渡す利用法もあります。

- **SEE** [man:icmp6(4freebsd)], [rfc:2292]
