# Socket::TCP_NOPUSH

### const TCP_NOPUSH -> Integer

[BasicSocket#getsockopt](../../../method/BasicSocket/i/getsockopt.md), [BasicSocket#setsockopt](../../../method/BasicSocket/i/setsockopt.md)
の第2引数(optname)に使用します。
