# JSON?.load_file

### module_function def load_file(filespec, opts = {}) -> object

filespec で指定した JSON 形式のファイルを Ruby オブジェクトとしてロードして返します。

- **param** `filespec` -- ファイル名を指定します。

- **param** `options` -- オプションをハッシュで指定します。指定可能なオプションは [JSON?.parse](../../../method/JSON/m/parse.md) と同様です。

- **SEE** [JSON?.parse](../../../method/JSON/m/parse.md)
