# OpenSSL::X509::DEFAULT_CERT_DIR

### const DEFAULT_CERT_DIR -> String

デフォルトの CA 証明書ディレクトリ名です。

[OpenSSL::X509::Store#set_default_paths](../../../method/OpenSSL=3a=3aX509=3a=3aStore/i/set_default_paths.md) で読み込まれます。

[OpenSSL::X509::DEFAULT_CERT_DIR_ENV](../../../method/OpenSSL=3a=3aX509/c/DEFAULT_CERT_DIR_ENV.md) で得られる環境変数よって上書き可能です。

証明書ディレクトリに含まれる証明書のファイル名はハッシュ名でなければなりません。
