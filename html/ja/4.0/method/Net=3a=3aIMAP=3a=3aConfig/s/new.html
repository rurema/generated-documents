    singleton method Net::IMAP::Config.new

    new(parent = Net::IMAP::Config.global, **attrs) -> Net::IMAP::ConfigRuby 3.4 から[permalink][rdoc][edit]
    new(parent = Net::IMAP::Config.global, **attrs) {|config| ... } -> Net::IMAP::Config

    parent を継承元とする新しい設定を作り、attrs で属性の値を設定して返します。

    parent は Net::IMAP::Config.[] で変換するので、設定のほかに版の数値や名前やハッシュも指定できます。ブロックを渡すと、作った設定をブロックに渡してから返します。

    [PARAM] parent:
    継承元の設定。省略時は全体の設定
    [PARAM] attrs:
    設定する属性の名前と値
    [EXCEPTION] ArgumentError:
    attrs に未知の属性名がある場合や、属性に不正な値を指定した場合に発生します。
    [EXCEPTION] TypeError:
    parent に設定に変換できないもの(nil など)を指定した場合に発生します。
    例 
    require 'net/imap'

config = Net::IMAP::Config.new(open_timeout: 10)
p config.open_timeout                            # => 10
p config.parent.equal?(Net::IMAP::Config.global) # => true
p Net::IMAP::Config.new(0.3).sasl_ir             # => false
