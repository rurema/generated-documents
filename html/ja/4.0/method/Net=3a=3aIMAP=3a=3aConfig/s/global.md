# Net::IMAP::Config.global

### def Net::IMAP::Config.global -> Net::IMAP::Config

全体の設定を返します。

[Net::IMAP.config](../../../method/Net=3a=3aIMAP/s/config.md) と同じオブジェクトです。
この設定は凍結されておらず、継承元は [Net::IMAP::Config.default](../../../method/Net=3a=3aIMAP=3a=3aConfig/s/default.md) です。
[Net::IMAP::Config.new](../../../method/Net=3a=3aIMAP=3a=3aConfig/s/new.md) で `parent` を省略したときや、[Net::IMAP.new](../../../method/Net=3a=3aIMAP/s/new.md) で `config` を省略したときの継承元になります。

- **SEE** [Net::IMAP.config](../../../method/Net=3a=3aIMAP/s/config.md), [Net::IMAP::Config.default](../../../method/Net=3a=3aIMAP=3a=3aConfig/s/default.md)
