# Net::IMAP::Config#idle_response_timeout

### def idle_response_timeout -> Integer

IDLE の応答を待つ秒数を返します。

[Net::IMAP#idle](../../../method/Net=3a=3aIMAP/i/idle.md) で IDLE を終えるよう要求してから、応答を受け取るまで待つ秒数です。
既定値は 5 です。
