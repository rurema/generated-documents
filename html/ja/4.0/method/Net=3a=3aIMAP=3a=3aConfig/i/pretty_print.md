# Net::IMAP::Config#pretty_print

### def pretty_print(pp) -> ()

[pp](../../../library/pp.md) で、すべての属性と継承の連鎖を表す文字列を出力するのに使います。

継承した属性は、それを継承した継承元とともに示します。

- **param** `pp` -- [PP](../../../class/PP.md) オブジェクト
