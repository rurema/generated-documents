# Kernel#find_type

### def find_type(type, opt, *headers) -> Array
### def find_type(type, opt, *headers){ ... } -> Array

静的な型 type がシステムに存在するかどうか検査します。

- **param** `type` -- 検査したい型の名前を指定します。

- **param** `opt` -- コンパイラに渡す追加のオプションを指定します。

- **param** `headers` -- 追加のヘッダを指定します。
