最後に成功したマッチで n 番目の括弧にマッチした値が格納されます。
該当する括弧がなければ nil が入っています。(覚え方: \数字 のようなもの)

番号 n は任意の正整数にできますが、巨大な数に対しては常に nil を返し、警告を表示します。

[`Regexp.last_match(1)`](../../../method/Regexp/s/last_match.md),
[`Regexp.last_match(2)`](../../../method/Regexp/s/last_match.md), ... と同じ。

これらの変数はローカルスコープかつスレッドローカル、読み取り専用です。

```ruby title="例"
str = '<p><a href="http://example.com">example.com</a></p>'
if %r[<a href="(.*?)">(.*?)</a>] =~ str
  print $1
  print $2
end
# => "http://example.com"
# => "example.com"
```
