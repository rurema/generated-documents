# Kernel$_

### gvar $_ -> String | nil

最後に [Kernel?.gets](../../../method/Kernel/m/gets.md) または [Kernel?.readline](../../../method/Kernel/m/readline.md) で読み込んだ文字列です。
EOF に達した場合には、 nil になります。
(覚え方: Perlと同じ)

[Kernel?.print](../../../method/Kernel/m/print.md) のような Perl 由来の幾つかのメソッドは、引数を省略すると代わりに $_ を利用します。

この変数はローカルスコープかつスレッドローカルです。
Ruby起動時の初期値は nil です。

- **SEE** [Kernel?.print](../../../method/Kernel/m/print.md), [Kernel?.gets](../../../method/Kernel/m/gets.md), [Kernel?.readline](../../../method/Kernel/m/readline.md), [Object::ARGF](../../../method/Object/c/ARGF.md)

### 例

example.txt:

```text
foo
bar
baz
```

このとき、コマンド ruby -e 'print while gets' example.txt は次を出力します

```text
foo
bar
baz
```

ただし、このプログラムは次のように書く方がよりRuby的です。

```ruby title="例"
ARGF.each do |line|
  print line
end
```
