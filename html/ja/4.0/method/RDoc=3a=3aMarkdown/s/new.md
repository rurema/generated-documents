# RDoc::Markdown.new

### def RDoc::Markdown.new(extensions = DEFAULT_EXTENSIONS, debug = false)

引数 extensions で与えられた拡張を有効にした [RDoc::Markdown](../../../class/RDoc=3a=3aMarkdown.md) オブジェクトを初期化します。

- **param** `extensions` -- 有効にする拡張を [Symbol](../../../class/Symbol.md) の配列で指定します。

- **param** `debug` -- デバッグを有効にするかどうかを指定します。
