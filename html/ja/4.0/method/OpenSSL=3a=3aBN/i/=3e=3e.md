# OpenSSL::BN#>>

### def >>(other) -> OpenSSL::BN

自身を other ビット右シフトした値を返します。

```ruby
require 'openssl'

bn = 2.to_bn
p bn >> 1  # => #<OpenSSL::BN 1>
p bn       # => #<OpenSSL::BN 2>
```

- **param** `other` -- シフトするビット数
- **raise** `OpenSSL::BNError` -- 計算時エラー
- **SEE** [OpenSSL::BN#rshift!](../../../method/OpenSSL=3a=3aBN/i/rshift=21.md)
