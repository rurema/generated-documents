# OpenSSL::BN#<<

### def <<(other) -> OpenSSL::BN

自身を other ビット左シフトした値を返します。

```ruby
require 'openssl'

bn = 1.to_bn
pp bn << 1    # => #<OpenSSL::BN 2>
pp bn         # => #<OpenSSL::BN 1>
```

- **param** `other` -- シフトするビット数
- **raise** `OpenSSL::BNError` -- 計算時エラー
- **SEE** [OpenSSL::BN#lshift!](../../../method/OpenSSL=3a=3aBN/i/lshift=21.md)
