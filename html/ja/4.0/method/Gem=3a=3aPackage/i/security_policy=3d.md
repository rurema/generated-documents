# Gem::Package#security_policy=

### def security_policy=(policy)
{: since="2.0.0"}

- **param** `policy` -- [Gem::Security::Policy](../../../class/Gem=3a=3aSecurity=3a=3aPolicy.md) を指定します。nil の場合は署名を検証しません。
