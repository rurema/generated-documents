# Array#==

### def ==(other)    -> bool

自身と other の各要素をそれぞれ順に == で比較して、全要素が等しければ true を返します。そうでない場合には false を返します。

- **param** `other` -- 自身と比較したい配列を指定します。

- **SEE** [Object#==](../../../method/Object/i/=3d=3d.md)

```ruby title="例"
p [ "a", "c" ]    == [ "a", "c", 7 ]   # => false
p [ "a", "c", 7 ] == [ "a", "c", 7 ]   # => true
p [ "a", "c", 7 ] == [ "a", "d", "f" ] # => false
```
