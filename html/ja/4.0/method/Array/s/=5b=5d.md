# Array.[]

### def Array.[](*item)    -> Array

引数 item を要素として持つ配列を生成して返します。

[Array](../../../class/Array.md) のサブクラスを作成したときに、そのサブクラスのインスタンスを作成しやすくするために用意されている。

- **param** `item` -- 配列の要素を指定します。

```ruby title="例"
p Array[1, 2, 3] # => [1, 2, 3]

class SubArray < Array
  # ...
end
p SubArray[1, 2, 3] # => [1, 2, 3]
```
