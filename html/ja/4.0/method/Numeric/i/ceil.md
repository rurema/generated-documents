# Numeric#ceil

### def ceil   -> Integer

自身と等しいかより大きな整数のうち最小のものを返します。

```ruby title="例"
p 1.ceil      # => 1
p 1.2.ceil    # => 2
p (-1.2).ceil # => -1
p (-1.5).ceil # => -1
```
