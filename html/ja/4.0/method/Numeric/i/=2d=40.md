# Numeric#-@

### def -@    -> Numeric

`0` から `self` を引いた値を返します。

`self` が実数の場合、符号反転です。

このメソッドは、二項演算子の `-` で `0 - self` として定義されています。

`Numeric` オブジェクトに対する単項演算子 `-` はこのメソッドの呼び出しになります。
