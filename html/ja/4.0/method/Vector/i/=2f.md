# Vector#/

### def /(other) -> Vector

`self` の各要素を数 `other` で割ったベクトルを返します。

- **param** `other` -- `self` の各要素を割る [Numeric](../../../class/Numeric.md) オブジェクトを指定します。
- **raise** `ExceptionForMatrix::ErrOperationNotDefined` -- `other` が [Vector](../../../class/Vector.md) や [Matrix](../../../class/Matrix.md)
       の場合に発生します
