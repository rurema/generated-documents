# Vector#+

### def +(v) -> Vector | Matrix

`self` にベクトル `v` を加えたベクトルを返します。

`v` には column_size が 1 の [Matrix](../../../class/Matrix.md) オブジェクトも指定できます。
その場合は返り値も [Matrix](../../../class/Matrix.md) オブジェクトになります。

- **param** `v` -- 加算するベクトル。加算可能な行列やベクトルを指定します。

- **raise** `ExceptionForMatrix::ErrDimensionMismatch` -- `self` と引数のベクトルの要素の数(次元)が異なっていたときに発生します。
