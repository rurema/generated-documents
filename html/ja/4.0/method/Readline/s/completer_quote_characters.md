# Readline.completer_quote_characters

### def Readline.completer_quote_characters -> String

ユーザの入力の補完を行う際、スペースなどの単語の区切りをクオートするための複数の文字で構成される文字列を取得します。

- **raise** `NotImplementedError` -- サポートしていない環境で発生します。
