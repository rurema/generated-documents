# SingleForwardable#delegate

### def single_delegate(hash) -> ()
### def delegate(hash)        -> ()

メソッドの委譲先を設定します。

- **param** `hash` -- 委譲先のメソッドがキー、委譲先のオブジェクトが値の
            [Hash](../../../class/Hash.md) を指定します。キーは [Symbol](../../../class/Symbol.md)、
            [String](../../../class/String.md) かその配列で指定します。
