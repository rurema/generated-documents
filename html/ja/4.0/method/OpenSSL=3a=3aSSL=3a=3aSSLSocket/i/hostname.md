# OpenSSL::SSL::SSLSocket#hostname

### def hostname -> String | nil

TLS の Server Name Indication 拡張で利用するサーバのホスト名を返します。

[OpenSSL::SSL::SSLSocket#hostname=](../../../method/OpenSSL=3a=3aSSL=3a=3aSSLSocket/i/hostname=3d.md) で設定した値がそのまま返されます。

設定していない場合は nil を返します。
