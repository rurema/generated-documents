# Dir.[]

### def Dir.[](*pattern, base: nil, sort: true)                            -> [String]

ワイルドカードの展開を行い、パターンにマッチするファイル名を文字列の配列として返します。
flags を指定しない [Dir.glob](../../../method/Dir/s/glob.md) と同じです。パターンやワイルドカードの詳細は [Dir.glob](../../../method/Dir/s/glob.md) を参照してください。

- **param** `pattern` -- パターンを文字列で指定します。複数指定できます。

- **param** `base` -- [Dir.glob](../../../method/Dir/s/glob.md) の base と同じです。

- **param** `sort` -- [Dir.glob](../../../method/Dir/s/glob.md) の sort と同じです。

```ruby
p Dir["*"]           # => ["foo", "bar"]
p Dir["f*", "b*"]    # => ["foo", "bar"]
```

- **SEE** [Dir.glob](../../../method/Dir/s/glob.md)
