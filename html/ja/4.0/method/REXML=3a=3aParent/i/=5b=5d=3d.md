# REXML::Parent#[]=

### def []=(index, node)
### def []=(range, node)
### def []=(start, length, node)

子ノード列上の指定した場所を node で置き換えます。

[Array#\[\]=](../../../method/Array/i/=5b=5d=3d.md) と同じ指定が可能です。

- **param** `index` -- 変更場所の index ([Integer](../../../class/Integer.md))
- **param** `range` -- 変更場所の範囲 ([Range](../../../class/Range.md))
- **param** `start` -- 変更範囲の最初の位置 ([Integer](../../../class/Integer.md))
- **param** `length` -- 変更範囲の個数 ([Integer](../../../class/Integer.md))
- **param** `node` -- 置き換えるノード
