    instance method DBM#store

    store(key, value) -> String[permalink][rdoc][edit]

    key に対して value を格納します。

    [PARAM] key:
    キー。
    [PARAM] value:
    値。

    [SEE_ALSO] DBM#[]=

db1 = DBM.open('aaa.db', 0666, DBM::NEWDB)
p db1.store('c', 'ccc') #=> "ccc"
