# IRB::Context#auto_indent_mode=

### def auto_indent_mode=(val)

入力が次の行に継続した時に自動で字下げを行うかどうかを val に設定します。

- **param** `val` -- true を指定した場合、自動で字下げを行います。false を指定した場合は自動で字下げを行いません。

[IRB::Context#prompt_mode](../../../method/IRB=3a=3aContext/i/prompt_mode.md) の変更に影響を受ける事に注意してください。
