# IRB::Context#use_tracer=

### def use_tracer=(val)

irb への入力を評価する時に `tracer` によるトレース出力を有効にするかどうかを val で指定します。

.irbrc ファイル中で IRB.conf[:USE_TRACER] を設定する事でも同様の事が行えます。

- **param** `val` -- トレース出力を有効にする場合に true を指定します。

- **SEE** [IRB::Context#use_tracer](../../../method/IRB=3a=3aContext/i/use_tracer.md)
