# Range#%

### def %(s)        -> Enumerator
### def %(s)        -> Enumerator::ArithmeticSequence

範囲内の要素を s おきに繰り返す [Enumerator](../../../class/Enumerator.md) を返します。
ブロックを指定しない [Range#step](../../../method/Range/i/step.md) と同じです。

- **param** `s` -- [Range#step](../../../method/Range/i/step.md) の s と同じです。
- **return** -- 数値の Range の時は [Enumerator::ArithmeticSequence](../../../class/Enumerator=3a=3aArithmeticSequence.md) を返します。
- **return** -- その他の Range の時は [Enumerator](../../../class/Enumerator.md) を返します。(例: String の Range)

```ruby title="例"
p ((1..10) % 3).to_a     # => [1, 4, 7, 10]
p (("a".."f") % 2).to_a  # => ["a", "c", "e"]
```

- **SEE** [Range#step](../../../method/Range/i/step.md)
