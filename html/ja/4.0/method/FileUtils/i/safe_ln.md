# FileUtils#safe_ln

### def safe_ln(*args)

安全にリンクを作成します。

リンクの作成に失敗した場合はファイルをコピーします。

- **param** `args` -- [FileUtils?.cp](../../../method/FileUtils/m/cp.md), [FileUtils?.ln](../../../method/FileUtils/m/ln.md) に渡す引数を指定します。

- **SEE** [FileUtils?.cp](../../../method/FileUtils/m/cp.md), [FileUtils?.ln](../../../method/FileUtils/m/ln.md)
