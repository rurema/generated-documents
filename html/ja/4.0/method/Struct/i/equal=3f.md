# Struct#equal?

### def equal?(other)   -> bool

指定された other が self 自身である場合のみ真を返します。
これは [Object](../../../class/Object.md) クラスで定義されたデフォルトの動作です。

[注意] 本メソッドの記述は Struct の下位クラスのインスタンスに対して呼び出す事を想定しています。Struct.new は Struct の下位クラスを作成する点に注意してください。
