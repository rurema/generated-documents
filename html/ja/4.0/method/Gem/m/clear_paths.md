# Gem?.clear_paths

### module_function def clear_paths -> nil

[Gem?.dir](../../../method/Gem/m/dir.md), [Gem?.path](../../../method/Gem/m/path.md) の値をリセットします。

次に [Gem?.dir](../../../method/Gem/m/dir.md), [Gem?.path](../../../method/Gem/m/path.md) が呼ばれた時は、値を最初から計算します。
このメソッドは主にユニットテストの独立性を提供するために使用します。
