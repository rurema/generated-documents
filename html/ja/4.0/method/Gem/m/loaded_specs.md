# Gem?.loaded_specs

### module_function def loaded_specs -> {String => Gem::Specification}
{: since="1.9.2"}

読み込み済みの [Gem::Specification](../../../class/Gem=3a=3aSpecification.md) を、Gem 名をキーにしたハッシュで返します。

- **return** -- Gem 名をキー、読み込み済みの [Gem::Specification](../../../class/Gem=3a=3aSpecification.md) を値とするハッシュです。
