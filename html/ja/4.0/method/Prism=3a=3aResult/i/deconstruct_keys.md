# Prism::Result#deconstruct_keys

### def deconstruct_keys(keys) -> Hash

パターンマッチのハッシュパターンで使われます。`comments`・`magic_comments`・`data_loc`・`errors`・`warnings` をキーに持つハッシュを返します。

- **param** `keys` -- 取り出したいキーの配列を指定します。すべて取り出す場合は nil を指定します。
