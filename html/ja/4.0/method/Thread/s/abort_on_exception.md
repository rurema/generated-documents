# Thread.abort_on_exception

### def Thread.abort_on_exception             -> bool

いずれかのスレッドが例外によって終了した時に、その例外をメインスレッドで再度発生させるかどうかを返します。

デフォルトは false です。

[Thread#exception](../../../class/Thread.md#exception)を参照してください。
