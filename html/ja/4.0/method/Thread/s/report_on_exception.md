# Thread.report_on_exception

### def Thread.report_on_exception             -> bool

いずれかのスレッドが例外によって終了した時に、その内容を $stderr に報告するかどうかを返します。

デフォルトは true です。
詳細は [Thread.report_on_exception=](../../../method/Thread/s/report_on_exception=3d.md) を参照してください。
