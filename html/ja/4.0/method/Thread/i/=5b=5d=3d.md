# Thread#[]=

### def []=(name,val)

val を name に対応するスレッド固有のデータとして格納します。

- **param** `name` -- スレッド固有データのキーを文字列か [Symbol](../../../class/Symbol.md) で指定します。文字列を指定した場合は [String#to_sym](../../../method/String/i/to_sym.md) によりシンボルに変換されます。

- **param** `val` -- スレッド固有データを指定します。nil を指定するとそのスレッド固有データは削除されます。
