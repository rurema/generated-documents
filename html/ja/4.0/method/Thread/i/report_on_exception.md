# Thread#report_on_exception

### def report_on_exception               -> bool

そのスレッドが例外によって終了した時に、その内容を $stderr に報告するかどうかを返します。

デフォルトはスレッド作成時の [Thread.report_on_exception](../../../method/Thread/s/report_on_exception.md) です。
