# Pathname#mkpath

### def mkpath(mode: nil) -> self

FileUtils.mkpath(self.to_s) と同じです。

`self` を返します。


- **param** `mode` -- 作成するディレクトリのパーミッションを8進数で指定します。[FileUtils?.mkpath](../../../method/FileUtils/m/mkpath.md) の `mode` と同じです。

- **SEE** [FileUtils?.mkpath](../../../method/FileUtils/m/mkpath.md)
