    instance method Symbol#capitalize

    capitalize(*options) -> SymbolRuby 1.9.3 から[permalink][rdoc][edit]
    () → Symbol
    (:ascii | :lithuanian | :turkic) → Symbol
    (:lithuanian, :turkic) → Symbol
    (:turkic, :lithuanian) → Symbol

    シンボルに対応する文字列の先頭の文字を大文字に、残りを小文字に変更したシンボルを返します。

    (self.to_s.capitalize.intern と同じです。) 

    p :foobar.capitalize   # => :Foobar
p :fooBar.capitalize   # => :Foobar
p :FOOBAR.capitalize   # => :Foobar
p :"foobar--".capitalize # => "Foobar--"
