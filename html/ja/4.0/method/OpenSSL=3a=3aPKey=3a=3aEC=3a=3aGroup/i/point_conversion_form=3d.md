# OpenSSL::PKey::EC::Group#point_conversion_form=

### def point_conversion_form=(sym)

点のエンコーディング方式を設定します。

以下のいずれかを設定します。
  - :compressed
  - :uncompressed
  - :hybrid
詳しくは  X9.62 (ECDSA) などを参照してください。

- **param** `sym` -- 設定する方式([Symbol](../../../class/Symbol.md))
