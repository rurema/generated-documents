# Net::IMAP.encode_utf7

### def Net::IMAP.encode_utf7(str) -> String

UTF-8 の文字列を modified UTF-7 の文字列に変換します。

modified UTF-7 は IMAP のメールボックス名に使われるエンコーディングで、
UTF-7 を修正したものです。

詳しくは [Net::IMAP.encode_utf7](../../../method/Net=3a=3aIMAP/s/encode_utf7.md) を見てください。

- **param** `str` -- 変換対象の UTF-8 でエンコードされた文字列
- **SEE** [Net::IMAP.decode_utf7](../../../method/Net=3a=3aIMAP/s/decode_utf7.md)
