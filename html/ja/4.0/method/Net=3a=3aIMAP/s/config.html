    singleton method Net::IMAP.config

    config -> Net::IMAP::ConfigRuby 3.4 から[permalink][rdoc][edit]

    全体の設定 Net::IMAP::Config.global を返します。

    Net::IMAP.new で config を省略すると、接続ごとの設定 Net::IMAP#config はこの設定を継承します。

    例 
    require 'net/imap'

p Net::IMAP.config.equal?(Net::IMAP::Config.global) # => true
p Net::IMAP.config.open_timeout                     # => 30

    [SEE_ALSO] Net::IMAP::Config, Net::IMAP#config
