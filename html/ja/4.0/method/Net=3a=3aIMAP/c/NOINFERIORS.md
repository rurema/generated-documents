# Net::IMAP::NOINFERIORS

### const NOINFERIORS -> Symbol

「:Noinferiors」というシンボルを返します。

このメールボックスの下に子レベルの階層が存在不可能であることを意味します。

詳しくは [RFC:2060] を参照してください。
