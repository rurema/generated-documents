# Net::IMAP::UNMARKED

### const UNMARKED -> Symbol

「:Unmarked」というシンボルを返します。

メールボックスが印付けられていないことを意味します。
メールボックスに新しいメールが届いていないことを意味します。

LIST応答の属性
([Net::IMAP#list](../../../method/Net=3a=3aIMAP/i/list.md)、[Net::IMAP::MailboxList#attr](../../../method/Net=3a=3aIMAP=3a=3aMailboxList/i/attr.md))
として用いられます。

詳しくは [RFC:2060] を参照してください。
