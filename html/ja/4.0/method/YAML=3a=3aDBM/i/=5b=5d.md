# YAML::DBM#[]

### def [](key) -> object | nil

データベースからキーを探して対応する要素の値を返します。

対応する値が見つからなかった場合は nil を返します。[DBM#\[\]](../../../method/DBM/i/=5b=5d.md) とは異なり、[IndexError](../../../class/IndexError.md) は発生しません。

- **param** `key` -- キーを文字列で指定します。

- **SEE** [YAML::DBM#fetch](../../../method/YAML=3a=3aDBM/i/fetch.md)
