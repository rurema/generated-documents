# REXML::Attributes#<<

### def add(attribute) -> ()
### def <<(attribute) -> ()

属性を追加/更新します。

attribute で更新する属性([REXML::Attribute](../../../class/REXML=3a=3aAttribute.md) オブジェクト)を指定します。既に同じ名前([REXML::Namespace#name](../../../method/REXML=3a=3aNamespace/i/name.md))のオブジェクトが存在する場合は属性が上書きされ、ない場合は追加されます。

- **param** `attribute` -- 追加(更新)する属性([REXML::Attribute](../../../class/REXML=3a=3aAttribute.md) オブジェクト)
- **SEE** [REXML::Attributes#\[\]=](../../../method/REXML=3a=3aAttributes/i/=5b=5d=3d.md)
