# Prism::Node#===

### def ===(other) -> bool

`other` が自身と同じクラスで、位置情報を除く各フィールドの内容が
(再帰的に `===` で)一致する場合に true を返します。位置情報は「存在するかどうか」だけが比較され、実際の値(オフセットなど)は比較されません。

- **param** `other` -- 比較対象のオブジェクトを指定します。

```ruby title="例"
require "prism"

a = Prism.parse("1 + 2").value
b = Prism.parse("1 + 2").value
p a === b # => true
```
