# Regexp#==

### def ==(other) -> bool
### def eql?(other) -> bool

`self` が `other` と同じパターン、オプション、文字コードの正規表現オブジェクトであったら `true` を、そうでなければ `false` を返します。

- **param** `other` -- 比較対象の正規表現オブジェクト

```ruby title="例"
p /^eee$/   == /~eee$/x   # => false
p /^eee$/   == /~eee$/i   # => false
p /^eee$/e  == /~eee$/u   # => false
p /^eee$/ == Regexp.new("^eee$") # => true
p /^eee$/.eql?(/^eee$/)          # => true
```
