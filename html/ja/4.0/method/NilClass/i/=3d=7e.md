# NilClass#=~

### def =~(other) -> nil
{: since="2.6.0"}

右辺に正規表現オブジェクトを置いた正規表現マッチ obj =~ /RE/
をサポートするためのメソッドです。常に nil を返します。

`Object#=~` が deprecated になった Ruby 2.6 で、nil に対するマッチを警告なしに行えるよう追加されました（`Object#=~` は Ruby 3.2 で削除されています）。


- **param** `other` -- 任意のオブジェクトです。結果に影響しません。

```ruby title="例"
obj = 'regexp'
p(obj =~ /re/) #=> 0

obj = nil
p(obj =~ /re/) #=> nil
```
