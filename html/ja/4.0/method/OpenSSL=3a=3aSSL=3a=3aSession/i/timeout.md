# OpenSSL::SSL::Session#timeout

デフォルト値は [OpenSSL::SSL::SSLContext#timeout=](../../../method/OpenSSL=3a=3aSSL=3a=3aSSLContext/i/timeout=3d.md)
で設定されます。
