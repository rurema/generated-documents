# Fiber.[]=

### def Fiber.[]=(key, value)

現在のファイバーの fiber storage の key に対応する値を value に設定します。
key に対応する値がまだない場合は追加します。

このファイバーから生成したファイバーには、設定した値が引き継がれます。
逆に、生成後の変更は互いに影響しません。

- **param** `key` -- キーを [Symbol](../../../class/Symbol.md) で指定します。
- **param** `value` -- 格納する値を指定します。
- **raise** `TypeError` -- key を [Symbol](../../../class/Symbol.md) として扱えない場合に発生します。

key には [String](../../../class/String.md) も指定できます。この場合 [Symbol](../../../class/Symbol.md) に変換されて扱われます。

```ruby
Fiber[:key] = 1

Fiber.new do
  p Fiber[:key] # => 1
  Fiber[:key] = 2
  p Fiber[:key] # => 2
end.resume

# 生成したファイバー側での変更は生成元に影響しない
p Fiber[:key]   # => 1
```
