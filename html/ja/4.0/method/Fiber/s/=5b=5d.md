# Fiber.[]

### def Fiber.[](key) -> object | nil

現在のファイバーの fiber storage から key に対応する値を返します。
対応する値がない場合は nil を返します。

fiber storage については [Fiber#storage](../../../method/Fiber/i/storage.md) を参照してください。

- **param** `key` -- キーを [Symbol](../../../class/Symbol.md) で指定します。
- **raise** `TypeError` -- key を [Symbol](../../../class/Symbol.md) として扱えない場合に発生します。

key には [String](../../../class/String.md) も指定できます。この場合 [Symbol](../../../class/Symbol.md) に変換されて扱われます。

```ruby
Fiber[:key] = 1

p Fiber[:key]     # => 1
p Fiber[:unknown] # => nil
```
