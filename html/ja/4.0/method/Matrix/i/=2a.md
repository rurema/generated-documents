# Matrix#*

### def *(m) -> Matrix | Vector

self に行列またはベクトル m を右から乗じた行列を返します。

m が [Vector](../../../class/Vector.md) オブジェクトなら返り値も [Vector](../../../class/Vector.md) オブジェクトになります。

- **param** `m` -- 右からの乗算が定義可能な行列やベクトルを指定します。

- **raise** `ExceptionForMatrix::ErrDimensionMismatch` -- 次元が合わない場合に発生します

### def *(other) -> Matrix

self の各成分に数 other を掛けた行列を返します。

- **param** `other` -- self の各成分に掛ける [Numeric](../../../class/Numeric.md) オブジェクトを指定します。
