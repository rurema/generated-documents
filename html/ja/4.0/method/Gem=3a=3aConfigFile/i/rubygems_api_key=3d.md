# Gem::ConfigFile#rubygems_api_key=

### def rubygems_api_key=(api_key)
{: since="1.9.2"}

rubygems.org の API キーを設定し、認証情報ファイルに書き込みます。

- **param** `api_key` -- API キーを文字列で指定します。
