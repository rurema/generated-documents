# Gem::ConfigFile#install_extension_in_lib

### def install_extension_in_lib -> bool

拡張ライブラリを、拡張ライブラリ用のディレクトリだけでなく `lib` にもインストールするかどうかを返します。

デフォルトは真([Gem::ConfigFile::DEFAULT_INSTALL_EXTENSION_IN_LIB](../../../method/Gem=3a=3aConfigFile/c/DEFAULT_INSTALL_EXTENSION_IN_LIB.md))です。
