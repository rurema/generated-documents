# Gem::ConfigFile#disable_default_gem_server=

### def disable_default_gem_server=(flag)
{: since="2.0.0"}

`gem push` でホストの明示を必須にするかどうかを設定します。

- **param** `flag` -- 真を指定すると、`gem push` でホストを明示する必要があります。
