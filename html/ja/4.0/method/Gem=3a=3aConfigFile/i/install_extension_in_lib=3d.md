# Gem::ConfigFile#install_extension_in_lib=

### def install_extension_in_lib=(flag)

拡張ライブラリを、拡張ライブラリ用のディレクトリだけでなく `lib` にもインストールするかどうかを設定します。

- **param** `flag` -- 真を指定すると `lib` にもインストールします。
