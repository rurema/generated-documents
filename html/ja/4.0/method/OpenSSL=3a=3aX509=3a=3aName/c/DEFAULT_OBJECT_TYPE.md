# OpenSSL::X509::Name::DEFAULT_OBJECT_TYPE

### const DEFAULT_OBJECT_TYPE -> Integer

属性値のデフォルトの ASN.1 の型です。

[OpenSSL::X509::Name.parse](../../../method/OpenSSL=3a=3aX509=3a=3aName/s/parse.md) や [OpenSSL::X509::Name.new](../../../method/OpenSSL=3a=3aX509=3a=3aName/s/new.md) で
template に指定されなかった属性はこの型であると仮定して処理されます。

[OpenSSL::ASN1::UTF8STRING](../../../method/OpenSSL=3a=3aASN1/c/UTF8STRING.md) を返します。
