# WEBrick::HTTPResponse#[]=

### def []=(field, val)

レスポンスの該当するヘッダに val を設定します。

- **param** `field` -- ヘッダ名を文字列で指定します。大文字と小文字を区別しません。

- **param** `val` -- ヘッダの値を指定します。to_s メソッドによって文字列に変換されます。

```ruby
require 'time'
res['last-modified'] = Time.now.httpdate
```
