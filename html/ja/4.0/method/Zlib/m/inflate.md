# Zlib?.inflate

### module_function def inflate(string) -> String

引数 string を展開します。[Zlib::Inflate.inflate](../../../method/Zlib=3a=3aInflate/s/inflate.md) と同じです。

- **param** `string` -- 展開する文字列を指定します。

- **raise** `Zlib::NeedDict` -- 展開に辞書が必要な場合に発生します。

- **SEE** [Zlib::Inflate.inflate](../../../method/Zlib=3a=3aInflate/s/inflate.md)
