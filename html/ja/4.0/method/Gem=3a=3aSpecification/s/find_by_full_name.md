# Gem::Specification.find_by_full_name

### def Gem::Specification.find_by_full_name(full_name) -> Gem::Specification | nil

指定した `full_name` にもっとも合致する仕様書を返します。

見つからなかった場合は nil を返します。

- **param** `full_name` -- 探す仕様書の [Gem::Specification#full_name](../../../method/Gem=3a=3aSpecification/i/full_name.md) を文字列で指定します。

- **SEE** [Gem::Specification.find_all_by_full_name](../../../method/Gem=3a=3aSpecification/s/find_all_by_full_name.md)
