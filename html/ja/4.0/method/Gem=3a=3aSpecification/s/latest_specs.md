# Gem::Specification.latest_specs

### def Gem::Specification.latest_specs(prerelease = false) -> [Gem::Specification]
{: since="1.9.3"}

インストールされている最新の仕様書の一覧を返します。

- **param** `prerelease` -- true を指定するとプレリリース版の仕様書も対象に含めます。
