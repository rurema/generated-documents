# Gem::Specification#required_ruby_version=

### def required_ruby_version=(requirement)

- **param** `requirement` -- [Gem::Requirement.create](../../../method/Gem=3a=3aRequirement/s/create.md) が受け付ける形式のオブジェクトを指定します。
