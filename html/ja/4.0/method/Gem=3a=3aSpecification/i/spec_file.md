# Gem::Specification#spec_file

### def spec_file -> String
{: since="1.9.3"}

この spec の gemspec ファイルへのフルパスを返します。

例えば `/usr/local/lib/ruby/gems/3.4/specifications/rfoo-1.0.gemspec` のような
パスです。
