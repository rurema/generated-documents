# Gem::Specification#dependent_gems

### def dependent_gems -> Array

この Gem に依存している全ての Gem の情報のリストを返します。

それぞれのエントリは配列になっており、各要素は以下のようになっています。

0. [Gem::Specification](../../../class/Gem=3a=3aSpecification.md)
1. [Gem::Dependency](../../../class/Gem=3a=3aDependency.md)
2. [Gem::Specification](../../../class/Gem=3a=3aSpecification.md) の配列
