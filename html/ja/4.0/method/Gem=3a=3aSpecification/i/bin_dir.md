# Gem::Specification#bin_dir

### def bin_dir -> String
{: since="1.9.3"}

インストールされた gem の実行ファイル格納ディレクトリへのフルパスを返します。

[Gem::Specification#bindir](../../../method/Gem=3a=3aSpecification/i/bindir.md) とは異なり、こちらはフルパスを返します。
