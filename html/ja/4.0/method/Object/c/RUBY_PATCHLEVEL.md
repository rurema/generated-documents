# Object::RUBY_PATCHLEVEL

### const RUBY_PATCHLEVEL -> 0

Ruby のパッチレベルを表す [Integer](../../../class/Integer.md) オブジェクトです。

Ruby 4.0 以降はパッチレベルの増分をやめたため、リリース版では常に 0 になります（master などの開発版では -1 になります）。

パッチレベルという概念および RUBY_PATCHLEVEL 定数は、 Ruby 1.8.5-p1 以降、 1.8.6 以降で導入されました。
1.8.5やそれ以前のバージョンでは定義されていません。
