# Object#private_methods

### def private_methods(include_inherited = true) -> [Symbol]

そのオブジェクトが理解できる private メソッド名の一覧を返します。

- **param** `include_inherited` -- 偽となる値を指定すると自身のクラスのスーパークラスで定義されたメソッドを除きます。
