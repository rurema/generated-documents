# Gem::Server#root

### def root(request, response) -> ()

メソッド名に対応する URI に対するリクエストを処理するメソッドです。

- **param** `request` --  [WEBrick::HTTPRequest](../../../class/WEBrick=3a=3aHTTPRequest.md) オブジェクトが自動的に指定されます。

- **param** `response` -- [WEBrick::HTTPResponse](../../../class/WEBrick=3a=3aHTTPResponse.md) オブジェクトが自動的に指定されます。
