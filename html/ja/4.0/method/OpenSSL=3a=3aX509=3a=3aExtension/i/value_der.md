# OpenSSL::X509::Extension#value_der

### def value_der -> String

拡張領域の値(extnValue)を DER 形式にエンコードしたバイト列のまま返します。

[OpenSSL::X509::Extension#value](../../../method/OpenSSL=3a=3aX509=3a=3aExtension/i/value.md) が可読な文字列に変換した値を返すのに対し、こちらは加工前の生のオクテット列を返します。
