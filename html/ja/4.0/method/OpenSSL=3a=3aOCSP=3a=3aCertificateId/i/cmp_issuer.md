# OpenSSL::OCSP::CertificateId#cmp_issuer

### def cmp_issuer(other) -> bool

2つの CertificateId オブジェクトの issuer(証明書発行者)を比較し、同じ issuer であれば真を返します。

- **param** `other` -- 比較する [OpenSSL::OCSP::CertificateId](../../../class/OpenSSL=3a=3aOCSP=3a=3aCertificateId.md) オブジェクト
- **SEE** [OpenSSL::OCSP::CertificateId#cmp](../../../method/OpenSSL=3a=3aOCSP=3a=3aCertificateId/i/cmp.md)
