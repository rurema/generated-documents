# DateTime.rfc822

### def DateTime.rfc2822(str = 'Mon, 1 Jan -4712 00:00:00 +0000', start = Date::ITALY) -> DateTime

- **param** `str` -- 日付をあらわす文字列
- **param** `start` -- グレゴリオ暦をつかい始めた日をあらわすユリウス日
