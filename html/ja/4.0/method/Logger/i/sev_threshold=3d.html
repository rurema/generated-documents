    instance method Logger#level=

    level=(level)[permalink][rdoc][edit]
    sev_threshold=(level)

    Logger オブジェクトのログレベルを設定します。ログレベルがこれより低いメッセージは出力されません。

    [PARAM] level:
    ログレベルを指定します。
    例 
    require 'logger'

logger = Logger.new(STDOUT)
p logger.level # => 0
logger.level = Logger::Severity::ERROR # => 3
p logger.level # => 3
