    function rb_funcall_with_block

    [edit]
    VALUE rb_funcall_with_block(VALUE recv, ID mid, int argc, const VALUE *argv, VALUE procval)

    rb_funcallv_public と同じですが、ブロックを渡せます。ブロックには Proc のインスタンスを指定します。 to_proc による変換が必要なときは、この関数に渡す前に済ませてください。ただし nil とシンボルは特別に受け付けます。

    [PARAM] recv:
    メソッドのレシーバです。
    [PARAM] mid:
    呼び出すメソッドの名前です。
    [PARAM] argc:
    argv の要素数です。
    [PARAM] argv:
    メソッドに渡す引数の配列です。
    [PARAM] procval:
    ブロックとして渡す Proc、シンボル、または nil です。
    [RETURN]
    呼び出したメソッドの返り値です。
    [EXCEPTION] NoMethodError:
    メソッドがないとき、またはメソッドが private か protected のとき。
    [EXCEPTION] Exception:
    呼び出したメソッドの中で例外が発生したとき。
