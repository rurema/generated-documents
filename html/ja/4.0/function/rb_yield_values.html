    3. rb_yield_values

    function rb_yield_values

    [edit]
    VALUE rb_yield_values(int n, ...)

    n 個の引数をブロックに yield します。 rb_yield と同じですが、引数を可変長で渡します。 Ruby の引数 1 つにつき、C の引数 1 つを使います。

    [PARAM] n:
    ブロックに渡す引数の個数です。
    [PARAM] ...:
    ブロックに渡す引数です。n 個渡します。
    [RETURN]
    ブロックの評価結果です。
    [EXCEPTION] LocalJumpError:
    ブロックが渡されていないとき。
