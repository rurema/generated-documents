# library rexml

Pure Ruby の XML パーサです。
DOM スタイルと SAX スタイルの両方をカバーしています。

DOM スタイルの API を使うためには [rexml/document](../library/rexml=2fdocument.md) を使います。

SAX スタイルの API には、
  - [rexml/parsers/sax2parser](../library/rexml=2fparsers=2fsax2parser.md)
  - [rexml/parsers/streamparser](../library/rexml=2fparsers=2fstreamparser.md)
のいずれかを用います。

また、それ以外のパーサとして
  - [rexml/parsers/pullparser](../library/rexml=2fparsers=2fpullparser.md)
  - [rexml/parsers/ultralightparser](../library/rexml=2fparsers=2fultralightparser.md)
などもあります。
