# library webrick/httpservlet

このファイルを [Kernel?.require](../method/Kernel/m/require.md) すると、
[WEBrick::HTTPServlet::FileHandler](../class/WEBrick=3a=3aHTTPServlet=3a=3aFileHandler.md) に対して拡張子 .cgi と .rhtml のためのハンドラを設定します。

[webrick](../library/webrick.md) や [webrick/httpserver](../library/webrick=2fhttpserver.md) を [Kernel?.require](../method/Kernel/m/require.md) するとこのライブラリも一緒に [Kernel?.require](../method/Kernel/m/require.md) されます。
