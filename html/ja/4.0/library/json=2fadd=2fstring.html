    library json/add/string

    [edit]

    要約

    String に、生の文字列を JSON 形式の文字列に変換するメソッドや JSON のオブジェクトから文字列を生成するメソッドを定義します。

    これらのメソッドは Ruby 3.4 までは json を require するだけで定義されていました。

    追加・再定義されるメソッド

    String#to_json_raw String#to_json_raw_object String.json_create
