    module function Gem.#find_latest_files

    find_latest_files(glob, check_load_path = true) -> [String]Ruby 2.1.0 から[permalink][rdoc][edit]

    glob にマッチするパスを、最新バージョンの Gem や $LOAD_PATH から探して返します。

    Gem.#find_files と異なり、同じ Gem については最新バージョンのファイルだけを返します。

    [PARAM] glob:
    検索するファイルパスのパターンです。
    [PARAM] check_load_path:
    真の場合、$LOAD_PATH からも検索します。省略した場合は真になります。
    [RETURN]
    見つかったファイルパスの配列です。

    [SEE_ALSO] Gem.#find_files
