    singleton method ENV.has_key?

    has_key?(key) -> bool[permalink][rdoc][edit]
    include?(key) -> bool
    key?(key) -> bool
    member?(key) -> bool

    key で指定される環境変数が存在する時、真を返します。

    [PARAM] key:
    環境変数の名前を指定します。文字列で指定します。文字列以外のオブジェクトを指定した場合は to_str メソッドによる暗黙の型変換を試みます。
