    self[substr] -> String | nilRuby 1.9.3 から[permalink][rdoc][edit]
    slice(substr) -> String | nil

    self が substr を含む場合、一致した文字列を新しく作って返します。

    (self.to_s[substr] と同じです。)

    p :foobar.slice("foo") # => "foo"

    self[regexp, nth = 0] -> String | nilRuby 1.9.3 から[permalink][rdoc][edit]
    slice(regexp, nth = 0) -> String | nil

    正規表現 regexp の nth 番目の括弧にマッチする最初の部分文字列を返します。

    (self.to_s[regexp, nth] と同じです。)

    [PARAM] regexp:
    正規表現を指定します。
    [PARAM] nth:
    取得したい正規表現レジスタのインデックスを指定します。 
    p :foobar[/bar/] # => "bar"
p :foobarbaz[/(ba.)(ba.)/, 0] # => "barbaz"
p :foobarbaz[/(ba.)(ba.)/, 1] # => "bar"
p :foobarbaz[/(ba.)(ba.)/, 2] # => "baz"

    slice(range) -> String | nil

    rangeで指定したインデックスの範囲に含まれる部分文字列を返します。

    (self.to_s[range] と同じです。)

    [PARAM] range:
    取得したい文字列の範囲を示す Range オブジェクトを指定します。 
    p :foo[0..1] # => "fo"
