    instance method Time#as_json

    as_json(*args) -> HashRuby 3.0 から Ruby 4.1 で削除[permalink][rdoc][edit] [added by json/add/time]

    self を JSON 形式の文字列に変換する際に使う、中間表現となるハッシュに変換して返します。 Time#to_json が内部で使用しています。

    ハッシュには、JSON.create_id をキーとしてクラス名が、's' に 1970-01-01 からの経過秒数(Time#tv_sec の返り値)が、'n' にナノ秒未満の端数(Time#tv_nsec の返り値)が入ります。

    [PARAM] args:
    無視されます。
    例 
    require 'json/add/time'

t = Time.at(1700000000, 123456, :usec)
hash = t.as_json
p hash['json_class'] # => "Time"
p hash['s']           # => 1700000000
p hash['n']           # => 123456000
