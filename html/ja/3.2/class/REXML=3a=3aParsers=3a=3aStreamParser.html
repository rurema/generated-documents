    ストリームパーサオブジェクトを生成します。

    入力(文字列、IO、IO互換オブジェクト(StringIOなど))

    コールバックオブジェクト

    インスタンスメソッド

    add_listener(listener) -> ()[permalink][rdoc][edit]

    パーサのイベントを受け取るオブジェクト listener を登録します。

    REXML::Parsers::StreamParser.new に渡すコールバックオブジェクトとは別のものです。REXML::Parsers::StreamParser#parse でパースしている間、パーサが XML を読み進めてイベントが発生するたびに listener.receive(event) が呼び出されます。

    event は、先頭がイベントの種類を表すシンボルで、その後にパラメータが続く配列です。イベントの種類は rexml/parsers/pullparser/イベントの種類とパラメータ に挙げたものと同じですが、text のパラメータは正規化文字列だけです。また、文書の終わりで [:end_document] が通知されます。

    複数の listener を登録できます。

    [PARAM] listener:
    receive メソッドを持つオブジェクト

    [SEE_ALSO] rexml/validation/relaxng

    例 
    require 'rexml/parsers/streamparser'
require 'rexml/streamlistener'

class EventPrinter
  def receive(event)
    p event
  end
end

class MyListener
  include REXML::StreamListener
end

parser = REXML::Parsers::StreamParser.new("<a><b>text</b></a>", MyListener.new)
parser.add_listener(EventPrinter.new)
parser.parse
# >> [:start_element, "a", {}]
# >> [:start_element, "b", {}]
# >> [:text, "text"]
# >> [:end_element, "b"]
# >> [:end_element, "a"]
# >> [:end_document]
