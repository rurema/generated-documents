names=caption visibility=public kind=defined source_location=manual/api/cgi/html.md ### def caption(align = nil) -> String ### def caption(align = nil){ ... } -> String caption 要素を生成します。 ブロックを与えると、ブロックを評価した結果が内容になります。 - **param** `align` -- 配置を文字列で指定します。(top, bottom, left right が指定可能です) 属性をハッシュで指定することもできます。 ```ruby title="例" caption("left") { "Capital Cities" } # => Capital Cities ```
