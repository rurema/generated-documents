string
form("get"){ "string" } #
string
form("get", "url"){ "string" } #
string
``` ### def form(attributes) -> String ### def form(attributes){ ... } -> String form 要素を生成します。 ブロックを与えると、ブロックを評価した結果が内容になります。 - **param** `attributes` -- 属性をハッシュで指定します。 ```ruby title="例" form({"METHOD" => "post", ENCTYPE => "enctype"}){ "string" } #
string
