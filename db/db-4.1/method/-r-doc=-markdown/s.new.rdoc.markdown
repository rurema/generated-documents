### def RDoc::Markdown.new(extensions = DEFAULT_EXTENSIONS, debug = false)

引数 extensions で与えられた拡張を有効にした [c:RDoc::Markdown] オブジェクトを初期化します。

- **param** `extensions` -- 有効にする拡張を [c:Symbol] の配列で指定します。

- **param** `debug` -- デバッグを有効にするかどうかを指定します。
