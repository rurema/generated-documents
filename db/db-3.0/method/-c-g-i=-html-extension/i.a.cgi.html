names=a visibility=public kind=defined source_location=manual/api/cgi/html.md since_by_name= until_by_name= ### def a(href = "") -> String ### def a(href = ""){ ... } -> String a 要素を生成します。 ブロックを与えると、ブロックを評価した結果が内容になります。 - **param** `href` -- 文字列を指定します。属性をハッシュで指定することもできます。 ```ruby title="例" a("http://www.example.com") { "Example" } # => "Example" a("HREF" => "http://www.example.com", "TARGET" => "_top") { "Example" } # => "Example" ```
