names=img visibility=public kind=defined source_location=manual/api/cgi/html.md ### def img(src = "", alt = "", width = nil, height = nil) -> String img 要素を生成します。 - **param** `src` -- src 属性の値を指定します。 - **param** `alt` -- alt 属性の値を指定します。 - **param** `width` -- width 属性の値を指定します。 - **param** `height` -- height 属性の値を指定します。 ```ruby title="例" img("src", "alt", 100, 50) # ``` ### def img(attributes) -> String img 要素を生成します。 - **param** `attributes` -- 属性をハッシュで指定します。 ```ruby title="例" img({ "SRC" => "src", "ALT" => "alt", "WIDTH" => 100, "HEIGHT" => 50 }) # ```
