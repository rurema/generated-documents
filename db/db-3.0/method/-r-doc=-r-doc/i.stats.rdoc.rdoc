### def stats -> RDoc::Stats | nil
{: since="1.9.1"}

[m:RDoc::RDoc#document] でドキュメントを生成した後に、解析の統計情報を [c:RDoc::Stats] オブジェクトで返します。
生成する前は nil を返します。
